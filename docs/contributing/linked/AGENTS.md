# SKEWNONO 와의 관계

이 저장소는 SKEWNONO(장비 작업 공간 허브)의 실험실 메뉴에서 링크로 연결되는
**독립 앱**입니다. SKEWNONO 의 코드는 이 저장소에 없고, 이 저장소의 코드도 SKEWNONO 에
들어가지 않습니다.

- SKEWNONO 쪽 진입 주소: `/<slug>` (SKEWNONO 소유자가 관리)
- 이 앱의 실제 URL: `<URL>`
- 소유자: `<이름>`
- SKEWNONO API 사용: `<안 함 / 서버에서 토큰으로>`

## 반드시 지킬 것

1. **SKEWNONO 를 가정하지 않습니다.** SKEWNONO 의 쿠키, 헤더, 디자인 토큰, 컴포넌트는
   여기서 쓸 수 없습니다. 신원이 필요하면 이 앱 자체의 게이트를 만듭니다.
2. **SKEWNONO API 는 서버에서만 부릅니다.** 브라우저에서 SKEWNONO 의 `/api/*` 를
   부르는 코드를 쓰지 않습니다. CORS 와 쿠키 때문에 동작하지 않습니다. 서버에서
   `Authorization: Bearer <토큰>` 으로 부릅니다. 토큰은 코드나 저장소에 넣지 않고
   환경 변수로 받습니다.
3. **SKEWNONO 응답 규약.** 실패는 `{"error": {"code", "message"}}` 와 `4xx`/`5xx`
   입니다. 503 은 사내 소스를 못 읽은 것이므로 잠시 뒤 재시도할 수 있고, 401 은
   토큰이 무효인 것이므로 재시도하지 않습니다.
4. **요청 수.** 토큰 소유자 기준 SKEWNONO `/api/*` 예산이 50 req / 5 s 입니다. 서버에서
   캐시하고, 화면 렌더마다 SKEWNONO 를 두드리지 않습니다.
5. **진입 주소를 퍼뜨리지 않습니다.** 사용자에게 알려 주는 주소는 SKEWNONO 의
   `/<slug>` 이고 이 앱의 URL 은 그 뒤에 숨습니다. 나중에 위치가 바뀌어도 링크가
   살아남게 하기 위해서입니다.
6. **SKEWNONO 저장소를 고치지 않습니다.** 진입 페이지와 메뉴 한 줄은 SKEWNONO
   소유자에게 patch 로 넘깁니다 (`docs/contributing/linked/README.md`).
