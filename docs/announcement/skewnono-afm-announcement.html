SKEWNONO AFM 페이지 오픈 안내

AFM 측정 결과 · 시계열 비교 · 팁 모니터링 · 가동 현황을 한곳에서

안녕하십니까. 계측 장비 통합 관리·분석 플랫폼 SKEWNONO에 AFM 페이지를 오픈하게 되어 안내드립니다.

지금까지 SKEWNONO는 CD-SEM · HV-SEM을 대상으로 했습니다. 이번에 AFM 3대(MAP608 · MAPC01 · 5EAP1501)의 측정 데이터를 더해, 측정 결과 조회부터 여러 측정의 시계열 비교, 팁 상태 모니터링, 장비 가동 · Recipe 현황까지 한 서비스에서 확인하실 수 있습니다.
 

주요 기능

01 측정 결과 검색 · 상세
Lot ID · Recipe · 날짜로 검색하고, 측정을 열면 측정 정보, 사이트별 요약, 측정 포인트 표와 분포 차트, 포인트별 프로파일과 이미지를 한 화면에서 봅니다. 상세 화면은 Excel로 내려받거나 링크를 복사해 그대로 공유할 수 있습니다.
02 시계열 비교
검색 결과에서 고른 측정을 데이터 그룹에 담아 함께 봅니다. 평균 ± 3σ 관리선을 그은 추세, 포인트별 비교, lot 간 · wafer 내 변동을 나눈 그룹 통계, 장비 건강 지표, 측정 소요시간을 차례로 보여 줍니다. 자주 보는 묶음은 이름을 붙여 저장해 두고 다시 불러옵니다.
03 팁 모니터링
지금 장착된 팁과 팁별 Tip Width 추이를 같은 팁 종류의 관리선과 비교해 정상 · 주의 · 이상으로 판정합니다. Recipe를 고르면 그 Recipe의 측정만으로 다시 판정합니다.
04 가동 현황
일별 · 시간대별 측정 건수와 미완료 · 무효 측정을 7일 / 30일 / 전체 기간으로 봅니다. 날짜를 누르면 그날의 측정 목록으로 이어집니다.
05 Recipe 현황
Recipe별 측정 건수, 처음 · 마지막 측정일, 사용한 팁을 정리합니다. 최근 7일 안에 측정한 Recipe, 30일 넘게 측정이 없는 Recipe, 1회만 측정한 Recipe를 골라 볼 수 있습니다.
