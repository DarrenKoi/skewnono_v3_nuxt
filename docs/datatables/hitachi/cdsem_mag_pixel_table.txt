methematical relationships

FOV (Field of View) in micrometers

FOV = 135000 / Mag

135000 is constant (screen width in um at 1x magnification of the tool = 135 mm)

Pixel Size in nanometers

Pixel Size = FOV X 1000 / N_pixels


In datatable, the columns are
Mag, Fov, pixels (512, 1024, 2048, 4096)
