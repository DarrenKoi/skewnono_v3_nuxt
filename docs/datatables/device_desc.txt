모든 팹에서 사용되는 개발 디바이스 정보 
R3, R4도 포함되어 있지만 R3, R4의 경우 r3_device_grp를 주로 사용 (최신 정보 반영되어 있음)

Column -> Type: Value 설명
모든 컬럼과 밸류는 string Type
주의: 결측이 섞여 있습니다 — 실제 None/NaN 뿐 아니라 문자열 "None" 이
그대로 들어 있는 cell 도 있습니다. 어댑터는 둘 다 빈 값("")으로
정규화해야 합니다 (recipe_tat office adapter 의 _text 참고).

fac_id -> fab 이름 (fab_name처럼 fab 내 세부적인 표현 없음)
lot_cd -> 3 or 4 Alphabets and Numbers, normally Starts with RAEA, RAAJ, 4MJ, 7EC. 3글자인 경우 맨 앞 숫자는 Fab을 지칭 (M17), R은 연구개발 디바이스
ctn_desc -> 개발 디바이스에 대한 간략한 설명 ("pool제", "Pool", "풀" 단어 포함 여부 중요), t-EV, tev, p-EV, PV, TV 등 개발 phase 정보 포함. 개발코드 명도 포함되어 있음
chg_tm -> 개발 정보 등록 또는 변경된 시점 (예: 2019-09-30T17:30:33Z)
tech_nm-> 테크 코드 (예, TP, 4G, AA, 7D), None
rnd_connector -> 연구 개발에서 이용된 테크 코드명 (lot_cd가 R로 시작할 경우 tech_nm과 rnd_connector는 같은 value 사용)

========================================================================
사무실(Office) 실데이터 소스 — Redis
========================================================================

사무실에서는 이 카탈로그가 Redis 에 pandas DataFrame 으로 저장됩니다.

Key   -> "device_desc" (DataFrame, parquet 직렬화)
         M 계열 양산 fab 카탈로그입니다. (user-confirmed 2026-07-31)
Column -> fac_id, lot_cd, ctn_desc, chg_tm, tech_nm, rnd_connector

R3/연구개발 카탈로그는 별도 key r3_device_grp 입니다
(docs/datatables/r3_device_grp.txt 참고). recipe_tat/fail_issue 가 공유하는
back_dev_home/ebeam/hitachi/_office_meas_hist.py 도 이 두 key 를 읽으므로,
한쪽만 바꾸면 같은 device 목록이 화면마다 달라집니다.

정정 사항

- 컬럼명: 이 문서는 이전에 사무실 컬럼명을 stn_desc 로 기록했으나, 실제
  컬럼명은 mock 과 동일한 ctn_desc 입니다. 한 번 엇갈린 전력이 있어
  device_statistics 어댑터는 ctn_desc -> stn_desc 순으로 찾는 관용을
  둡니다(providers/office_example.py 의 _DEVICE_DESC_COLUMNS).

- 이 카탈로그와 r3_device_grp 는 device-statistics 의 initial setup
  카탈로그입니다. 화면 요청에 따라 여기서 device code 를 추출해 사용합니다.

실제 컬럼/행 수/결측 분포는 사무실에서 아래로 확인합니다 (OFFICE-VERIFY):

    .venv/bin/python -m scripts.inspect_device_info_keys

사용 방법(recipe_tat 디바이스별 화면)

- device_desc 는 폐기된 lot_cd 까지 전부 포함하므로, OpenSearch
  ebeam_tas_lot_hist 의 최근 60일 unique lot_cd 와 교집합을 취해 "현재 생산
  중" device 만 표시합니다.
- fab_name 컬럼이 없으므로 화면 fab 선택은 fac_id 단위로 좁힙니다
  (M16A/B/C -> M16, R3/R4 -> R3).
- M fab device 의 tech_nm 은 그대로 사용합니다. R3/R&D 의 prod_catg_cd 는
  r3_device_grp 에서 가져옵니다(lot_cd 가 R 로 시작하면 tech_nm 과
  rnd_connector 가 같은 값).
