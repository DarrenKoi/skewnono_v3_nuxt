redis key: v3_df_ppid_storage_cdsem, v3_df_ppid_storage_hvsem

★ 이 DataFrame 의 fab_name / fac_id 컬럼은 신뢰하지 않습니다 (office 확인).
  수집 파이프라인이 fac 단위 이름("M16")을 fab_name 자리에 써 넣어서, 사이드바의
  fab_name 필터("M16A")가 아무것도 매칭하지 못했습니다. 그 결과 R3 를 제외한 모든
  fab 의 스토리지 table 이 빈 화면이었습니다.
  어댑터는 각 row 를 eqp_ip 기준으로 sem_list(장비 명부, 단일 진실 원천)에 다시
  대조해서 fab_name / fac_id / eqp_model_cd 를 채우고, 명부에 없는 IP 일 때만 DF 의
  값으로 fallback 합니다. docs/datatables/sem_list.txt 참고.
