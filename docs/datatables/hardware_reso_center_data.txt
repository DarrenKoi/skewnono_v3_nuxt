장비의 상태 모니터링. bm/pm시에 체크하고 data로 남기게 되어있다.
beam_shape, reso_center에 해당. reso_center는 CD-SEM 장비에서만 제공된다.

OpenSearch index alias: reso_center_cdsem (category "reso_center_log").

★ alias 와 category 를 혼동하지 말 것.
  조회하는 index(alias)  = reso_center_cdsem
  문서 안의 category 값  = reso_center_log
  "reso_center_log" 는 index 이름이 **아니다**. 이것을 index 로 조회하면 사무실에서
  index_not_found 가 난다. (2026-07-27 기준 back_dev_home 의 reso_center 템플릿·
  MIGRATION.md 는 reso_center_log 를 index 이름처럼 적고 있었고, 그것이 잘못이다.)

doc 하나에는 다음과 같은 필드가 있다.
'category': str "reso_center_log"
'CenterX': float 예 = 1.15
'CenterY': float -0.99
'BestReso': float 2.98         # best-focus resolution (focus sweep의 최소값)
'ResoIScenter': float 3.04     # 중심 focus에서의 resolution (>= BestReso)
'ResoDelta': float 0.06        # ResoIScenter - BestReso 의 차이 (>= 0)
'beam_condition': str 'HR0500_IP0080'
'timestamp': str '2026-04-20T12:55:16'
'timestamp_date': str '2026-04-20'
'eqp_id'
'eqp_ip'
'fac_id'
'fab_name'

표시 방식:
- fab_name -> 해당 fab의 eqp_ip(장비)를 고르고, beam_condition별로 시계열을
  표시한다.
- 시계열 차트는 BestReso와 ResoIScenter 두 선을 같은 y축(nm)에 그리며, 두 선의
  간격이 곧 ResoDelta 이다.
- Focus Sweep은 Resolution Center에서 사용하지 않는다. 따라서 이전에 있던
  Resolution_Range / Resolution_Range_Raw / Resolution_Range_Smooth 와
  fdc_category 필드는 더 이상 사용하지 않는다.
