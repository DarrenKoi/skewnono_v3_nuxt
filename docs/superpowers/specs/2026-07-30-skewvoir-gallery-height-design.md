# Skewvoir 이미지 갤러리 높이 조정 설계

## 목표

`skewvoir/analysis`의 이미지 갤러리에서 개별 썸네일의 정사각형 비율은
유지하면서, 이미지 목록의 스크롤 영역을 왼쪽 레일의 `ACTIONS > Share`
위치와 비슷한 높이까지 확장합니다.

## 현재 상태

단일 측정과 세트 측정의 이미지 그리드는 모두 `max-h-[34rem]`으로
제한되어 있습니다. 큰 화면에서는 이 고정 상한 때문에 워크스페이스에
남는 세로 공간을 사용하지 못하고 갤러리 아래에 빈 공간이 생깁니다.

## 검토한 방식

1. 고정 `rem` 상한을 더 큰 값으로 올리는 방식
   - 변경은 가장 작지만 화면 높이에 따라 다시 짧거나 길어질 수 있습니다.
2. 뷰포트 기반 `calc()` 높이를 지정하는 방식
   - 현재 레이아웃에는 맞출 수 있지만 상단 chrome 높이와 중복 결합됩니다.
3. 갤러리 패널을 세로 flex 컨테이너로 만들고 이미지 그리드가 남은 공간을
   채우도록 하는 방식
   - 워크스페이스의 실제 가용 높이를 따르며 화면 크기 변화에도 안정적입니다.

세 번째 방식을 사용합니다.

## 변경 범위

- `views/Gallery.vue` 안에서만 높이와 overflow 소유권을 조정합니다.
- `EvidenceCard.vue`의 `aspect-square`는 유지합니다.
- 단일 측정과 세트 측정 이미지 그리드에 같은 높이 정책을 적용합니다.
- 이미지 로딩, 필터, 다운로드, 확대 보기 동작은 변경하지 않습니다.
- 다른 Skewvoir 분석 화면과 공용 `PanelFrame.vue`는 변경하지 않습니다.

## 검증

- 단일 측정과 세트 측정에서 이미지 목록이 워크스페이스의 남은 세로 공간을
  사용하고, 아래쪽이 왼쪽 `Share` 액션과 비슷한 위치에 도달하는지 확인합니다.
- 썸네일이 정사각형으로 유지되는지 확인합니다.
- 이미지 목록 내부 스크롤과 전체 워크스페이스 스크롤이 충돌하지 않는지
  확인합니다.
- 프런트엔드 타입 검사와 관련 테스트를 실행합니다.
