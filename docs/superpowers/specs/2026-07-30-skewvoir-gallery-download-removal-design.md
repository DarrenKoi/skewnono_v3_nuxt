# Skewvoir 이미지 갤러리 전체 다운로드 제거 설계

**작성일:** 2026-07-30
**대상:** `skewvoir/analysis` 이미지 갤러리

## 목표

이미지 갤러리에서 `전체 다운로드` 액션을 당분간 노출하지 않습니다.
한 번에 많은 이미지를 장비와 캐시로 가져오면서 서비스가 느려지는 경로를
사용자가 실행하지 못하게 하는 것이 목적입니다.

## 범위

- `SEM Gallery` 헤더의 `전체 다운로드` 버튼을 제거합니다.
- 다운로드 진행률과 전체 작업 실패 안내 UI를 제거합니다.
- 갤러리 컴포넌트가 소유하던 다운로드 작업 시작, 폴링, 정리 상태를
  제거합니다.
- 단일 MSR 및 세트 범위의 이미지 표시, 필터, 이미지 뷰어와 개별 TIFF
  다운로드 동작은 유지합니다.

## 비범위

- `/api/msr-images`의 전체 다운로드 API는 제거하거나 차단하지 않습니다.
- `useMsrImageApi`의 다운로드 작업 함수와 백엔드 작업 처리 코드는
  변경하지 않습니다.
- 선택 파라미터 이미지 묶음 다운로드는 이번 변경에 추가하지 않습니다.
- 갤러리 레이아웃과 이미지 로딩 정책은 변경하지 않습니다.

## 구현 설계

변경은
`front-dev-home/app/components/ebeam/skewvoir/views/Gallery.vue`에만
한정합니다.

헤더의 다운로드 액션과 두 개의 오류·실패 표시 블록을 삭제합니다.
스크립트에서는 `DownloadJobStatus`, `downloadErrorMessage`,
`startDownloadAll`, `pollJob` 의존성과 폴링 상태·함수·watch를 함께
삭제합니다. 이미지 URL 생성과 뷰어 기능에 필요한 `imageUrl`은
그대로 유지합니다.

백엔드와 공용 composable을 보존하므로, 다운로드 기능을 기술적으로
안정화한 뒤 별도 설계를 통해 다시 공개할 수 있습니다.

## 오류 처리

전체 다운로드를 시작하는 UI가 없어지므로 해당 작업의 진행률과 오류
표시도 함께 없어집니다. 기존 이미지별 로딩 및 뷰어 오류 처리는 영향을
받지 않습니다.

## 검증

- 프런트엔드 전체 Node 테스트가 통과해야 합니다.
- 프런트엔드 typecheck가 통과해야 합니다.
- ESLint는 변경 파일만 검사합니다.
- 정적 확인으로 `Gallery.vue`에 `전체 다운로드`, 다운로드 작업 시작,
  폴링 상태가 남지 않았는지 확인합니다.
- 갤러리 이미지 URL 생성, 필터, 뷰어와 TIFF 개별 다운로드 마크업이
  유지되었는지 diff를 검토합니다.
