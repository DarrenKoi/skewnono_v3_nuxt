# SKEWNONO History 화면 설계

## 목표

`front-dev-home/app/pages/intro.vue`의 `시작하기` 영역에 독립적인
`History` 화면을 추가합니다. SKEWNONO v1과 v2는 간단히 설명하고, 현재 버전인
v3는 주요 기능을 자세히 소개합니다.

버전별 문구는 전용 데이터 파일에 모아 이후 릴리스 정보와 기능 설명을 쉽게 수정할
수 있도록 합니다.

## 범위

- `시작하기` 내비게이션에 `History` 항목을 추가합니다.
- 기존 소개 화면과 페이지별 가이드는 유지합니다.
- History 화면은 정적 콘텐츠로 제공하며 API와 백엔드는 변경하지 않습니다.
- 버전 이력 데이터는 `front-dev-home/app/data/skewnonoHistory.ts`에서 관리합니다.

## 콘텐츠 구조

### v1 · 2024

SKEWNONO의 첫 버전으로 다음 기능을 간단히 소개합니다.

- 장비 상태 확인
- 측정 이력 조회
- FDC 기반 Sharpness 모니터링

### v2 · 2025

CD-SEM 약 270대를 대상으로 서비스 범위가 확장된 버전으로 설명합니다. 장비와
Recipe 운영 정보를 더 폭넓게 확인할 수 있게 된 변화를 간단히 소개합니다.

### v3 · 2026.07

현재 버전으로 강조하고 다음 네 가지 기능 영역을 상세히 설명합니다.

1. **CD-SEM 및 HV-SEM 통합 관리**: CD-SEM 약 270대와 HV-SEM 약 50대,
   총 약 320대의 장비 상태와 운영 정보를 한곳에서 확인합니다.
2. **Hardware 및 Calibration 분석**: 주요 하드웨어 상태, FDC, Beam Calibration,
   BM/PM 정보를 측정 결과와 연결하여 장비 간 차이와 변화 원인을 확인합니다.
3. **Device Statistics 강화**: DRAM, NAND, New Memory별 Device와 CD Step의
   Recipe 및 Parameter 현황, 계측 룰 위반과 변화 추이를 분석합니다.
4. **Skewvoir 분석**: 측정 결과, Wafer 위치별 분포, 시간 변화, Parameter 상관관계,
   측정 이미지를 연결해 이상 징후와 원인을 단계적으로 분석합니다.

## 데이터 모델과 편집 방식

전용 데이터 파일은 버전 배열을 export합니다. 각 항목은 다음 필드를 가집니다.

- `version`: 화면에 표시할 버전입니다.
- `releasedAt`: 릴리스 연도 또는 연월입니다.
- `summary`: 버전의 핵심 변화를 설명하는 짧은 문장입니다.
- `features`: 기능 이름, 설명, 아이콘으로 구성된 배열입니다.
- `current`: 현재 버전을 강조하기 위한 선택 필드입니다.

화면은 배열 순서대로 이력을 렌더링합니다. 향후 v4를 추가할 때는 Vue 템플릿을
수정하지 않고 배열에 객체 하나를 추가하며, 기존 설명 변경도 해당 객체만 수정합니다.

## 화면 구성과 상호작용

`시작하기` 영역은 `SKEWNONO 소개`와 `History` 두 항목을 제공합니다. 기존
`activePageId` 상태에 `history` 값을 추가하여 같은 intro 페이지 안에서 화면을
전환합니다.

History 화면은 다음 순서로 구성합니다.

1. 페이지 제목과 2024년부터 현재까지의 발전사를 설명하는 짧은 도입문
2. 의미상 순서가 있는 세로형 버전 타임라인
3. v1과 v2의 간결한 설명 및 기능 태그
4. 현재 v3의 강조된 설명과 네 개의 상세 기능 카드

데스크톱에서는 연도와 버전 표식을 콘텐츠 옆에 배치합니다. 모바일에서는 표식과
콘텐츠를 한 열로 쌓아 읽기 순서를 유지합니다. 기존 zinc border, white/dark surface,
Lucide icon, semantic typography class를 재사용하여 소개 페이지와 일관된 모양을
유지합니다.

## 접근성

- 버전 이력은 의미상 순서를 나타내는 `ol`과 `li`로 구성합니다.
- 각 버전과 기능 영역에 계층이 명확한 제목을 제공합니다.
- `History` 내비게이션은 기존 선택 상태 스타일과 키보드 동작을 그대로 사용합니다.
- 현재 버전은 색상뿐 아니라 `현재 버전` 텍스트로도 표시합니다.

## 오류 및 빈 상태

콘텐츠는 빌드 시 포함되는 정적 데이터이므로 네트워크 오류 상태는 없습니다. 버전
항목의 `features`가 비어 있으면 기능 영역을 렌더링하지 않고 요약만 표시합니다.

  수동으로 확인합니다.
