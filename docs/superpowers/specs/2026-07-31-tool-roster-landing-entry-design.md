# 미연결 장비 랜딩 진입점과 표 밀도 개선 설계

- 날짜: 2026-07-31
- 상태: 승인됨
- 영역: `front-dev-home` 랜딩, 헤더 내비게이션, 미연결 장비 화면

## 배경

현재 미연결 장비 화면은 Topnav 아이콘을 통해 `/tool-roster`로 이동합니다.
페이지에 진입해도 데이터를 자동으로 불러오지 않으며, 사용자가 `조회` 버튼을
눌러야 집계표가 나타납니다.

미연결 장비는 시스템 연결 현황의 상세 후속 작업입니다. 따라서 전역 Topnav보다
랜딩의 `System Status` 바로 아래에서 접근하는 편이 정보 구조에 맞습니다. 다만
전사 장비 명부 API는 랜딩 진입만으로 호출하지 않습니다. 사용자가 미연결 장비를
보려는 의도를 표시해 `/tool-roster`로 이동했을 때 호출합니다.

현재 집계표는 카드 전체 너비를 채우면서 열 간격이 넓어집니다. 한눈에 여러 Fab과
모델을 비교하는 표이므로 콘텐츠 중심의 조밀한 밀도가 더 적합합니다.

## 목표

- 랜딩의 `System Status` 연결 현황 아래에서 미연결 장비 화면으로 이동합니다.
- 랜딩에서는 미연결 장비 API를 호출하지 않습니다.
- `/tool-roster` 진입 시 데이터를 자동으로 불러오고, 완료되면 표를 바로
  표시합니다.
- Topnav의 미연결 장비 아이콘과 링크를 제거합니다.
- 집계표와 드릴다운 표의 불필요한 여백을 줄입니다.

## 선택한 설계

### 랜딩 진입점

`front-dev-home/app/pages/index.vue`의 `System Status` 카드 바로 아래에
`미연결 장비 보기` 버튼을 배치합니다. 버튼은 Nuxt 내부 링크로
`/tool-roster`에 이동합니다.

랜딩은 기존 `useSemList()`와 `useBackendHealth()`만 사용합니다.
`usePendingTools()`를 호출하거나 미연결 장비 데이터를 미리 가져오지 않습니다.

### 페이지와 Topnav

`front-dev-home/app/pages/tool-roster.vue`는 유지합니다. 별도 경로는 여러 Tool
Type을 함께 다루는 전체 화면과 가로 스크롤 공간을 보존합니다.

`front-dev-home/app/utils/headerNav.ts`에서는 `/tool-roster` 항목을 제거합니다.
미연결 장비의 유일한 화면 진입점은 랜딩의 `System Status` 아래 버튼입니다.

### 자동 조회

`usePendingTools()`의 `useAsyncData`를 페이지 진입 시 실행되도록 변경합니다.
초기 상태는 `pending`이며 로딩 메시지를 표시합니다.

조회가 끝나면 다음 상태 중 하나를 렌더링합니다.

- 데이터가 있으면 필터, 집계표, 복사·다운로드 동작을 표시합니다.
- 데이터가 없으면 모든 장비가 연결되었다는 완료 상태를 표시합니다.
- 실패하면 오류 상태와 재시도 가능한 `새로고침` 버튼을 표시합니다.

기존 초기 `idle` 안내와 `조회` 버튼은 제거합니다. 헤더 버튼은 항상
`새로고침` 의미를 가지며, 로딩 중에는 비활성 로딩 상태를 표시합니다.
세션 내 `pending-tools` 캐시 키와 명시적 재조회 동작은 유지합니다.

### Compact 표

집계표는 카드 폭을 강제로 채우지 않고 내용 너비를 기준으로 렌더링합니다.
모델 열이 많아 사용 가능한 폭을 넘으면 현재처럼 표 컨테이너에서 가로
스크롤합니다.

다음 밀도 규칙을 집계표의 헤더, 본문, 합계 행에 일관되게 적용합니다.

- 셀의 좌우 패딩을 줄입니다.
- 셀의 상하 패딩과 행 높이를 줄입니다.
- 숫자 버튼의 작은 크기와 클릭 영역은 읽기와 조작에 필요한 수준으로
  유지합니다.
- 첫 번째 Fab 열과 마지막 합계 열은 데이터 열과 구분되도록 기존 타이포그래피를
  유지합니다.

드릴다운 `UTable`의 헤더와 본문 셀 패딩도 같은 밀도로 줄입니다. 정보 필드와
정렬 순서, hover 상태는 변경하지 않습니다.

## 변경하지 않는 범위

- `GET /api/sem-list/pending` 계약과 백엔드는 변경하지 않습니다.
- Tool Type 필터, Fab×모델 집계, 셀 드릴다운 규칙은 변경하지 않습니다.
- IP 목록 복사 형식과 CSV 다운로드 형식은 변경하지 않습니다.
- 기존 `/tool-roster` URL은 유지합니다.

## 검증

- 순수 집계 함수의 기존 프론트엔드 테스트를 실행합니다.
- Nuxt/Vue TypeScript 검사를 실행합니다.
- ESLint로 변경 파일을 포함한 프론트엔드를 검사합니다. 기존의 무관한 오류가
  있으면 이번 변경과 구분해 보고합니다.
- 실행 중인 앱에서 다음을 확인합니다.
  - 랜딩 진입만으로 `/api/sem-list/pending` 요청이 발생하지 않습니다.
  - `System Status` 아래 버튼이 `/tool-roster`로 이동합니다.
  - `/tool-roster` 진입 시 API 요청이 발생하고 표가 자동으로 나타납니다.
  - Topnav에 미연결 장비 아이콘이 없습니다.
  - 집계표와 드릴다운 표가 기존보다 조밀하며 작은 화면에서는 가로
    스크롤됩니다.
