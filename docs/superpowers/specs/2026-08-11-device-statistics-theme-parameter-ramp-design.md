# Device Statistics 테마 연동 파라미터 색상 설계

## 배경

`device-statistics/comparison`의 `파라미터 분포 (스택)`은 현재 하나의
적갈색 명도 램프를 사용합니다. 인접 구간이 같은 계열로 보여 사용자가 낮은
파라미터 수와 높은 파라미터 수를 빠르게 구분하기 어렵고, Settings에서 선택한
ECharts theme도 이 색상에 반영되지 않습니다.

이 변경은 파라미터 수가 낮은 구간을 차가운 색, 높은 구간을 따뜻한 색으로
표현하면서 선택한 ECharts theme의 시각적 정체성을 유지하는 것을 목표로 합니다.

## 사용자 경험

파라미터 구간은 다음 의미 순서를 유지합니다.

- `para_5`: 가장 차가운 테마 색입니다.
- `para_9`, `para_13`, `para_16`: 두 끝점 사이의 중간 색입니다.
- `para_over_16`: 가장 따뜻한 테마 색입니다.

Settings에서 ECharts theme를 바꾸면 비교 페이지의 차트, 범례, Lot 테이블 막대,
상세 모달 막대가 모두 즉시 같은 5단계 색상으로 갱신됩니다. 선택한 테마에 따라
끝점이 반드시 문자 그대로 파랑과 빨강일 필요는 없지만, 각 테마 안에서 가능한
한 차가운 색에서 따뜻한 색으로 진행합니다.

## 테마별 끝점

끝점은 런타임에서 색상 배열 순서를 추측하지 않고 각 테마의 기존 series
palette에서 명시적으로 선택합니다. 이렇게 하면 테마 palette 순서가 바뀌거나
첫 두 색의 의미가 반대여도 파라미터 의미가 뒤집히지 않습니다.

| Theme | Low anchor | High anchor |
| --- | --- | --- |
| Vintage | `#61a0a8` | `#d87c7c` |
| Dark | `#4992ff` | `#ff6e76` |
| Macarons | `#5ab1ef` | `#c05050` |
| Infographic | `#60C0DD` | `#C1232B` |
| Shine | `#0098d9` | `#c12e34` |
| Roma | `#6699FF` | `#E01F54` |
| MATLAB | `#0072BD` | `#A2142F` |

`Default`는 별도 끝점을 갖지 않습니다. 현재와 같이 Light 모드에서는 MATLAB,
Dark 모드에서는 Dark로 해석한 뒤 해당 테마의 끝점을 사용합니다.

## 색상 생성 계약

공용 순수 함수가 선택된 테마 이름으로부터 두 끝점을 읽고 RGB 공간에서 0%,
25%, 50%, 75%, 100% 위치를 보간하여 5개 색을 만듭니다. 반환값은 기존
`paraOrder` 키에 매핑된 객체입니다. `paraOrder`가 높은 구간부터 낮은 구간
순서이므로 매핑은 다음과 같습니다.

- `para_over_16`: 100% high anchor
- `para_16`: 75%
- `para_13`: 50%
- `para_9`: 25%
- `para_5`: 0% low anchor

호출부가 각각 색을 고르거나 보간하지 않습니다. 테마 끝점과 5단계 매핑은 한
유틸리티에서만 소유합니다.

## 구성 요소와 데이터 흐름

`useEchartsTheme()`이 이미 Settings의 저장된 선택값, color mode에 따른 실제
테마 이름, 변경 반응성을 제공합니다. 파라미터 색상 유틸리티는 이 실제 테마
이름을 입력으로 받습니다.

비교 페이지는 공용 램프를 사용하여 ECharts series와 카드 헤더 범례를 그립니다.
`StackedBar.vue`도 동일한 composable과 공용 램프를 사용하므로 Lot 테이블과 상세
모달이 차트와 같은 색을 유지합니다. 기존 `paraColors`와 `paraColorsDark`의 고정
램프는 제거하며, health 상태 색상은 변경하지 않습니다.

테마 변경 시 `useEchartsTheme()`의 반응형 값이 바뀌고, ECharts는 기존
`useEchart()` 경로로 다시 초기화됩니다. DOM 기반 막대와 범례도 computed 값이
다시 계산되어 별도 이벤트나 새 저장소 없이 갱신됩니다.

## 접근성

색상만으로 정확한 구간을 식별하도록 강제하지 않습니다. 기존 범례의
`para_*` 라벨, 막대 segment의 title, 스크린 리더용 aria-label을 그대로
유지합니다. 값이 0인 segment를 그리지 않는 현재 동작과 상세 모달의 숫자 표시
규칙도 유지합니다.

## 범위 제외

- API 응답, 파라미터 bucket 정의, 정렬, 합계 계산은 변경하지 않습니다.
- health, violation, outlier의 의미 색상은 변경하지 않습니다.
- Settings 화면의 테마 선택 UI와 저장 키는 변경하지 않습니다.
- `운용 레시피수` 단일 막대 차트의 테마 기본색은 변경하지 않습니다.
- 차트와 카드의 레이아웃 또는 문구는 변경하지 않습니다.

## 검증

순수 함수 테스트에서 다음을 확인합니다.

- 모든 선택 가능한 실제 테마에 low/high 끝점이 있습니다.
- 각 끝점은 해당 테마의 기존 series palette에 실제로 포함됩니다.
- 5단계 램프가 정확한 bucket 키를 가지며 `para_5`와 `para_over_16`이 지정한
  끝점과 일치합니다.
- `Default`의 Light/Dark 해석은 기존 테마 해석 규칙을 따릅니다.

프런트엔드 전체 테스트, typecheck, lint를 실행합니다. 실행 중인 앱에서는 Light와
Dark 모드에서 둘 이상의 ECharts theme를 바꾸어 차트, 범례, 테이블, 상세 모달이
동시에 갱신되고 각 surface에서 구분 가능한지 확인합니다.
