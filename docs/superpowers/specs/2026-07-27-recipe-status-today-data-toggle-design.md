# Recipe 현황 오늘 데이터 토글 설계

- 날짜: 2026-07-27
- 상태: 승인됨
- 영역: `front-dev-home` Recipe 현황의 일별 추이 차트

## 목표

Recipe TAT, Align Fail, Meas Fail의 일별 추이 차트에서 집계가 진행 중인
오늘 데이터를 기본적으로 제외합니다. 사용자가 필요할 때 `오늘 데이터`
스위치를 켜면 오늘까지 포함한 추이를 확인할 수 있습니다.

## 범위

변경 대상은 Recipe 현황의 세 일별 추이 차트입니다.

- Recipe TAT의 `Daily TAT trend`
- Align Fail의 `Align fail · daily trend`
- Meas Fail의 `Meas fail · daily trend`

랭킹, 요약 지표, 표, 다운로드, 선택한 날짜 범위, 전체 요약/디바이스별
필터와 백엔드 API 요청은 변경하지 않습니다.

## 사용자 경험

각 일별 추이 차트 헤더에 `오늘 데이터` 스위치를 표시합니다. 스위치의
기본값은 꺼짐입니다.

스위치 상태는 Recipe 현황 페이지를 보는 동안 세 탭에서 공유합니다.
예를 들어 Recipe TAT에서 스위치를 켜고 Align Fail로 이동하면 켜진 상태가
유지됩니다. 페이지를 새로고침하거나 다시 진입하면 기본값인 꺼짐으로
초기화합니다. URL 쿼리나 영속 저장소에는 기록하지 않습니다.

Fail 차트에서는 기존 Bar/Line/Ratio 선택기와 같은 헤더 오른쪽 영역에
스위치를 배치합니다. TAT 차트에서는 동일한 위치에 스위치만 배치합니다.
기존 차트 높이와 카드 레이아웃은 유지합니다.

## 데이터 처리

오늘 여부는 브라우저의 로컬 시각으로 계산하지 않고 기존 summary 응답의
`anchor_date`를 기준으로 판단합니다. 이 값은 mock과 office provider가
공유하는 데이터 기준일이므로 Phase 1의 고정 시각과 Phase 2/3의 실제
데이터 시각에서 동일한 의미를 유지합니다.

공유 순수 함수는 `{ date: string }` 형태의 일별 포인트 배열,
`anchor_date`, 스위치 상태를 입력으로 받습니다.

- 스위치가 켜져 있으면 모든 포인트를 반환합니다.
- 스위치가 꺼져 있으면 `date === anchor_date`인 포인트만 제외합니다.
- `anchor_date`가 없거나 현재 날짜 범위에 포함되지 않으면 입력 포인트를
  그대로 유지합니다.
- 입력 배열과 포인트 객체를 변경하지 않습니다.

TAT 차트의 x축, 값 시리즈, 툴팁은 필터링된 동일 포인트 배열을 사용합니다.
Align/Meas 차트도 x축, fail 값, 전체 측정 장수 기준선, Ratio 계산,
툴팁을 모두 필터링된 동일 포인트 배열에서 파생합니다. 따라서 포인트
인덱스가 어긋나지 않습니다.

## 컴포넌트 구조

`RecipeStatusView.vue`가 페이지 방문 동안 유지되는 Boolean 상태를
소유합니다. 이 상태를 `RecipeTatView.vue`와 `FailIssueView.vue`에
양방향 바인딩하여 어느 탭의 스위치를 조작해도 같은 값을 사용합니다.

일별 포인트 필터는 `app/utils/`의 순수 TypeScript 유틸리티로 분리합니다.
두 차트 컴포넌트는 원본 API 응답 대신 이 유틸리티가 만든 표시용 포인트를
ECharts 옵션에 전달합니다.

백엔드의 기간이나 응답 형태는 변경하지 않습니다. 스위치를 조작할 때
네트워크 재요청도 발생하지 않습니다.

## 예외 상태

선택한 범위가 오늘 하루뿐이고 스위치가 꺼져 있으면 차트에는 표시할
포인트가 없습니다. 이는 오늘 데이터를 제외한다는 선택의 직접적인
결과이므로 별도의 대체 데이터를 만들지 않습니다. 사용자는 같은 헤더의
스위치를 켜서 오늘 포인트를 표시할 수 있습니다.

데이터 로딩 중 이전 응답이 남아 있더라도 현재 응답의 summary와 daily
points에서 표시용 배열을 함께 계산합니다. `anchor_date`를 확인할 수
없는 순간에는 임의의 날짜를 제외하지 않습니다.

## 테스트와 검증

순수 유틸리티 테스트는 다음 동작을 검증합니다.

- 기본 꺼짐 상태에서 `anchor_date` 포인트만 제외합니다.
- 켜짐 상태에서 오늘 포인트를 포함한 전체 배열을 반환합니다.
- 과거 날짜 범위에는 영향을 주지 않습니다.
- `anchor_date`가 없을 때 임의로 포인트를 제거하지 않습니다.
- 입력 배열과 포인트 객체를 변경하지 않습니다.

구현 후 frontend 전체 테스트, typecheck, lint와 `git diff --check`를
실행합니다. 실행 중인 앱에서는 세 탭의 공유 상태, 새로고침 후 기본
꺼짐, Fail 차트의 Bar/Line/Ratio 전환, 날짜 범위와 디바이스 필터 변경을
확인합니다.

## 범위 제한

- 백엔드에 `include_today` 파라미터를 추가하지 않습니다.
- 오늘을 제외하기 위해 API의 종료일을 변경하지 않습니다.
- 스위치 상태를 URL, `useState`, local storage에 저장하지 않습니다.
- 일별 추이 이외의 차트와 표에는 이 필터를 적용하지 않습니다.
