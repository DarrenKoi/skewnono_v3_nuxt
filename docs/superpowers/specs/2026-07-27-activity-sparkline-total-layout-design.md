# Activity Sparkline 합계 레이아웃

- 날짜: 2026-07-27
- 상태: 승인됨

## 문제

`ActivitySparkline`은 시작 날짜, `합계 N`, 종료 날짜를 하나의 하단
`flex` 행에 표시합니다. 이 배치는 합계를 가운데 날짜 눈금처럼 보이게 하여
차트의 시간축 의미를 흐립니다.

## 선택한 설계

`합계 N`은 `ActivitySparkline` 내부에서 차트 바로 위의 독립된 우측 정렬
메타 행으로 이동합니다. 차트 아래 행에는 시작 날짜와 종료 날짜만
표시합니다.

이 방식은 다음 이유로 선택합니다.

- 두 사용 위치인 개인 활동 카드와 사용자 상세 행에 동일하게 적용됩니다.
- `series`와 `color` prop 및 활동 API 계약을 변경하지 않습니다.
- 페이지 카드 헤더를 변경하거나 새 slot/prop을 추가하지 않습니다.

검토한 다른 방식은 합계를 각 카드 헤더로 옮기는 방식과 합계를 제거하는
방식입니다. 카드 헤더 방식은 두 호출 위치의 구조를 함께 변경해야 하며,
제거 방식은 유용한 30일 누계 정보를 잃으므로 선택하지 않습니다.

## 검증

- 소스 기반 회귀 테스트에서 `합계`가 날짜 행과 분리되어 있는지 확인합니다.
- `npm test`, `npm run lint`, `npm run typecheck`를 실행합니다.
- 브라우저 세션을 사용할 수 있으면 활동 페이지에서 개인 카드와 사용자
  상세 행을 시각적으로 확인합니다.
