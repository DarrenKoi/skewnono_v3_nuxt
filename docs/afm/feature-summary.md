# AFM 페이지 제공 기능 요약

작성일: 2026-10-08

## 1. 배경

기존 `afm.skhynix.com` 페이지는 종료하고, AFM 측정 조회를 SKEWNONO 의 AFM 페이지로 통합합니다. 통합하면서 측정 조회 외에 시계열 비교, 팁 모니터링, 가동 현황, Recipe 현황을 함께 제공합니다.

이 문서는 2026-10-09 기준으로 SKEWNONO AFM 페이지가 제공하는 기능을 화면별로 정리합니다. 앞으로 검토 중인 추가 서비스는 [AFM 추가 서비스 추천 보고서](service-recommendations.md)에 있습니다.

## 2. 대상 장비와 화면 구성

대상 장비는 세 대입니다. 장비마다 fab 이 다르므로 한 화면에서 한 장비만 조회하며, 여러 장비의 측정을 합쳐 보여 주지 않습니다.

| 장비 | Fab |
| --- | --- |
| MAP608 | PKG |
| MAPC01 | R3 |
| 5EAP1501 | M15 |

첫 화면의 AFM Metrology 카드 또는 `/afm` 에서 장비를 고르면 해당 장비의 화면이 열립니다. 장비를 고른 뒤에는 상단에 탭 네 개가 나타납니다.

| 탭 | 경로 | 내용 |
| --- | --- | --- |
| 측정 결과 | `/afm/<장비>` | 측정 검색, 측정 상세, 시계열 비교 |
| 팁 모니터링 | `/afm/<장비>/tips` | 팁별 상태 판정과 Tip Width 추이 |
| 가동 현황 | `/afm/<장비>/usage` | 일별·시간대별 측정 건수 |
| Recipe 현황 | `/afm/<장비>/recipes` | Recipe 별 측정 이력 |

각 화면 상단의 장비 버튼으로 같은 화면을 유지한 채 다른 장비로 옮길 수 있습니다.

## 3. 측정 결과

### 3.1 측정 검색

- Lot ID, Recipe, 날짜를 한 검색창에서 검색합니다. (예: `CMP`, `T7HQR42TA`, `250609`)
- Recipe, Lot, 기간으로 결과를 좁히고, 결과 안에서 다시 필터할 수 있습니다.
- 검색어가 없으면 최근 측정을 보여 줍니다.
- 최근 검색어는 5개까지 기억합니다.
- 조회 기록 카드는 최근에 연 측정을 10건까지 보관하며, 누르면 바로 다시 엽니다.
- 데이터 그룹 카드는 검색 결과에서 체크한 측정을 담는 곳입니다. 한 그룹에 최대 20건을 담고, 이름을 붙여 10개까지 저장한 뒤 다시 불러올 수 있습니다. 담은 측정은 시계열 비교로 엽니다.

조회 기록, 데이터 그룹, 저장한 그룹은 장비별로 브라우저에 저장되므로 새로 고침 후에도 남습니다.

### 3.2 측정 상세

측정 한 건을 열면 다음 내용을 한 화면에서 봅니다. 왼쪽에서 포인트를 고르면 오른쪽 내용이 그 포인트로 바뀝니다.

| 영역 | 내용 |
| --- | --- |
| 측정 정보 | Info 항목 전체. 값을 누르면 복사합니다. |
| 측정 포인트 | 포인트 목록과 포인트별 상태. 스크롤해도 화면에 고정됩니다. |
| 같은 Lot·Slot 측정 | 같은 장비의 목록에서 Lot 과 Slot 이 같은 측정, 같은 Lot 의 다른 Slot 측정을 시간순으로 보여 주고 그룹에 한 번에 담습니다. |
| 포인트 요약 | 선택한 포인트의 측정값과 사이트 평균 대비 차이(Δ vs MEAN), 사이트별 요약 분포 차트 |
| Site 인덱스 격자 | 포인트를 `Site X`·`Site Y` 인덱스 자리에 놓고 고른 측정 항목의 값으로 칠합니다. 칸을 누르면 그 포인트가 선택됩니다. |
| 분석 이미지 | Align, Tip, Capture, Result 네 종류의 이미지 |
| 측정 포인트 표 | 포인트별 측정값, State, Valid. 블록이 여럿이면 Block 열을, 반복 측정 Recipe 이면 회차 열을 붙입니다. |
| 포인트 스캔 높이 맵 | 선택한 포인트 하나의 프로파일입니다. 2D 프로파일은 높이 맵으로, 라인 프로파일은 선 그래프로 그립니다. 웨이퍼 전체의 지도가 아닙니다. |
| 프로파일 이미지 | 선택한 포인트의 프로파일 이미지. PNG, JPG, 원본으로 저장합니다. |
| Z값 분포 | 선택한 포인트 프로파일의 Z값 히스토그램 |

분석 이미지는 팝업으로 크게 볼 수 있습니다.

- 포인트별로 묶은 전체 이미지 격자에서 원하는 이미지를 엽니다.
- 방향키(← →)로 이미지를 넘기고, 숫자 키 1~4 로 이미지 종류를 바꿉니다.
- 크기는 작게, 보통(원본 픽셀 크기), 크게, 맞춤 중에서 고릅니다.
- 이미지 한 장의 원본 파일을 내려받거나, 한 종류의 이미지 전체를 zip 으로 받습니다.

같은 Lot·Slot 측정 카드는 이전 측정을 검색해서 하나씩 담던 일을 대신합니다. (2026-10-09 추가)

- 지금 연 측정과 Lot·Slot 이 같은 측정을 `같은 Slot` 에, Lot 만 같은 측정을 `같은 Lot · 다른 Slot` 에 시간순으로 나열합니다. 행마다 측정 시각, Recipe, Lot, Slot, 그룹에 담겼는지를 표시하며 `상세` 로 그 측정을 엽니다.
- Slot 은 `5` 와 `05` 를 같은 Slot 으로 봅니다. Lot 이나 Slot 이 없는 측정은 자동으로 연결하지 않습니다. Lot 은 같지만 Slot 이 기록되지 않은 측정은 건수만 알립니다.
- `이 Slot 담기` 는 같은 Slot 의 측정을, `Lot 전체 담기` 는 다른 Slot 까지 그룹에 담습니다. 기본은 지금 연 측정과 같은 Recipe 만 담으며, 다른 Recipe 의 건수를 옆에 표시합니다. `같은 Recipe만` 을 끄면 모두 담습니다.
- 그룹의 남은 자리보다 측정이 많으면 지금 연 측정에 시간순으로 가까운 것부터 담고, 담지 못한 건수를 버튼을 누르기 전과 후에 모두 알립니다.
- 대상은 같은 장비의 목록(최근 3개월)입니다. Lot·Slot 이 같은 측정 후보이며, 같은 웨이퍼인지는 각 측정의 Sample ID 로 확인합니다. 목록에 없다는 것이 재측정이 없었다는 뜻은 아닙니다.

Site 인덱스 격자는 한 측정 안에서 값이 어느 Site 에서 높고 낮은지를 봅니다. (2026-10-09 추가)

- 측정 항목을 고르면 그 값으로 칸을 칠하고 색 범위의 최솟값과 최댓값을 표시합니다. 블록이 여럿인 측정은 블록도 고릅니다.
- `Site X`·`Site Y` 는 단위가 없는 정수 인덱스입니다. `Site Y` 가 큰 쪽을 위에 그립니다(사용자 확인 2026-10-09). 확인된 것은 Y 인덱스를 그리는 방향뿐입니다. notch 의 위치는 알 수 없고(사용자 확인 2026-10-09, 원본에 웨이퍼 방향 정보가 없습니다) `Site X` 의 방향과 mm 좌표와의 대응은 확인되지 않았으므로 웨이퍼 외곽선, notch, mm 축, 반경, 센터·에지 통계는 그리지 않습니다. 축 이름은 컬럼 이름 그대로입니다.
- State 가 COMPLETED 이고 Valid 가 FALSE 가 아닌 행의 값만 색으로 칠합니다. FAILED, STOPPED, Valid FALSE, 값이 없는 포인트는 ▲ 로 표시하며 낮은 값으로 칠하지 않습니다.
- 반복 측정 Recipe 는 포인트마다 마지막 회차의 값을 쓰고 회차 수를 표시합니다. 시계열 비교의 측정별 통계와 같은 규칙입니다.
- 한 Site 에 포인트가 여럿이면 유효한 값의 평균으로 칠하고 칸에 포인트 수를 적습니다. 칸을 다시 누르면 그 Site 의 다음 포인트가 선택됩니다.
- `Site X`·`Site Y` 를 기록하지 않는 Recipe 는 격자를 그리지 않고 그 사실을 표시합니다.

상세 화면에서 내보낼 수 있는 것은 다음과 같습니다.

- Excel 다운로드: 측정 정보, 사이트별 요약, 측정 포인트, 선택한 포인트의 프로파일을 한 파일로 받거나 항목별로 받습니다.
- 링크 복사: 이 측정으로 바로 오는 주소를 복사합니다. 받은 사람은 검색 없이 같은 측정을 엽니다.
- 차트 저장: 각 차트를 이미지로 저장합니다.

### 3.3 시계열 비교

데이터 그룹에 담은 측정(최대 20건)을 함께 열어 비교합니다. 화면 위쪽의 분석 조건(블록, 측정 항목, 통계)을 바꾸면 아래 카드가 모두 같은 조건으로 다시 그려집니다.

| 구역 | 카드 | 내용 |
| --- | --- | --- |
| 요약 | KPI | 그룹 평균(기준을 고정하면 기준 평균), lot 간 σ, wafer 내 σ̄, 기준 범위 밖 측정 수, FAILED·STOPPED 측정 수, 재측정 쌍 수 |
| 01 추세 | 시계열, 선택한 측정 | 측정마다 분포를 입히고 그룹의 평균 ± 3σ 를 그룹 기준 범위로 긋습니다. 범위 밖의 측정은 붉은 점으로 표시합니다. 선택한 측정 목록에서 기준으로 지정한 측정이 있으면 그 측정만으로 계산한 고정 기준 범위를 긋습니다. |
| 02 포인트별 비교 | 포인트 × 측정, 포인트 안정도 | x축을 포인트로 두어 센터·에지 패턴이 lot 마다 되풀이되는지, 한 포인트만 흘러가는지를 봅니다. |
| 03 그룹 통계 | 측정별 요약, 변동 분해, 재현성 | 측정별 요약 표, 변동이 lot 간에서 왔는지 wafer 안에서 왔는지의 분해, 같은 Sample ID 를 다시 잰 측정의 비교 |
| 04 장비 건강 | 측정별 상태 지표 | Tip Width, Mileage 평균, Approach Count 평균, FAILED + STOPPED 포인트 수의 네 지표를 2 × 2 로 놓고 한 슬라이더로 같은 구간을 함께 확대합니다. |
| 05 측정 소요시간 | 측정 소요시간 | Start Time 과 End Time 이 모두 기록된 측정만 계산합니다. 계산하지 못한 측정에는 이유를 표시합니다. 소요시간을 행 수로 나눈 포인트당 시간과 Recipe 별 중앙값을 함께 표시합니다. |
| 06 측정 항목 간 관계 | 항목 × 항목 | 같은 측정, 같은 포인트 행의 두 항목을 산점도의 한 점으로 찍습니다. X 에는 Mileage 와 Approach Count 도 놓을 수 있습니다. |
| 07 1D 프로파일 겹쳐 보기 | 라인 프로파일 × 측정 | 고른 포인트 하나의 라인 프로파일을 그룹의 측정끼리 한 차트에 겹칩니다. 그리지 않은 측정은 이유와 함께 차트 아래에 적습니다. |

- 그룹에 Recipe 가 섞여 있으면 경고를 띄웁니다. 같은 이름의 측정 항목이 Recipe 마다 같은 측정량이라는 보장이 없으므로, 추세는 Recipe 별 시리즈와 기준 범위로 나누고 변동 분해는 내지 않습니다.
- 기준 범위는 관리 한계나 규격이 아닙니다. 화면에 담은 측정에서 계산한 참고 범위이며, σ 는 MAD 기반으로 구합니다.
- 고정 기준선은 선택한 측정 목록의 `기준` 칩으로 지정합니다. 지정한 측정만으로 평균과 범위를 계산하므로 그룹에 측정을 더해도 기준이 움직이지 않습니다. 기준 측정 자신은 범위 밖 판정에서 빠지고, 나머지 측정만 판정합니다.
- 기준은 Recipe 마다 따로 계산합니다. 한 Recipe 의 기준 값이 2건 미만이면 범위를 긋지 않고 `기준 표본 부족`으로 표시합니다.
- 기준 지정은 장비별로 브라우저에 저장합니다. 그룹에서 뺀 측정은 기준에서도 빠집니다. 기준을 모두 해제하면 그룹 전체로 계산하는 원래 동작으로 돌아갑니다.
- 포인트별 비교는 기본으로 FAILED 행과 Valid FALSE 행의 값도 그립니다. (2026-10-09 추가) `FAILED · Valid FALSE 행` 을 `제외` 로 바꾸면 측정 항목 간 관계와 같은 규칙(State 가 COMPLETED 이고 Valid 가 FALSE 가 아님)을 통과한 행만 포인트 × 측정과 포인트 안정도에 씁니다. 유효한 행이 없는 포인트는 그 측정에서 빠지고, 반복 측정 포인트는 마지막 유효 회차의 값을 씁니다. 해당하는 행 수를 선택 옆에 표시하며, 선택은 브라우저에 저장합니다. 다른 구역의 통계는 바뀌지 않습니다.
- 측정 항목 간 관계는 선택한 블록의 숫자 항목 가운데 X 와 Y 를 골라 봅니다. (2026-10-09 추가) Y 는 분석 조건의 측정 항목에서 시작하며, 축에는 컬럼 이름을 그대로 씁니다. Mileage 는 단위가 확인되지 않았으므로 단위를 붙이지 않습니다.
- 점 하나는 행 하나입니다. State 가 COMPLETED 이고 Valid 가 FALSE 가 아닌 행만 쓰며, 제외한 행 수와 한쪽 값이 없는 행 수, Valid 가 기록되지 않은 행 수를 차트 아래에 표시합니다. 반복 측정 Recipe 는 회차마다 한 점입니다.
- 차트 아래에 표본 수 n 과 상관계수 r 을 표시합니다. 항목 간 차이는 지표로 내지 않습니다(같은 단위라도 같은 측정량이라는 보장이 없습니다). 두 값이 모두 있는 행이 3개 미만이면 차트와 통계를 내지 않고, 한 축의 값이 모두 같으면 r 을 계산 불가로 표시합니다.
- 이 관계는 직접 고른 그룹에서 관측된 것이며 원인을 뜻하지 않습니다. 회귀선, 합격·불합격 판정은 없습니다. Recipe 가 섞인 그룹은 포인트별 비교와 같이 선택한 측정의 Recipe 만 봅니다.
- 포인트당 시간은 소요시간을 그 측정의 측정 포인트 표 행 수로 나눈 값입니다. (2026-10-09 추가) 반복 측정 Recipe 는 회차마다 한 행으로 세고, 블록이 여럿이면 행이 가장 많은 블록 하나만 셉니다. FAILED·STOPPED 행도 장비가 시간을 쓴 측정이므로 셉니다. 나눈 행 수를 값 옆에 표시합니다.
- 소요시간이 없는 측정과 측정 포인트 표가 없는 측정에는 포인트당 시간을 내지 않습니다. 이 값은 기록상 시작·종료 간 경과시간을 나눈 것이며 순수 스캔 시간이나 가동률이 아닙니다.
- 1D 프로파일 겹쳐 보기는 선택한 측정의 포인트 목록에서 포인트 하나를 골라 봅니다. (2026-10-09 추가) `프로파일 불러오기` 를 눌러야 조회를 시작하며, 선택한 측정을 먼저 읽고 나머지 측정을 읽습니다. 한 번 읽은 측정·포인트는 페이지를 새로 고칠 때까지 다시 요청하지 않습니다.
- 함께 그리는 조건은 같은 Recipe, 같은 포인트 이름, 1D 라인, 같은 단위(X 와 Z)입니다. 기준 단위는 선택한 측정의 것입니다. 프로파일이 없는 측정, 2D 격자, 단위가 다르거나 단위 정보가 없는 프로파일, 조회에 실패한 측정은 그리지 않고 이유를 적습니다. 선택한 측정이 2D 격자이면 나머지 측정은 조회하지 않고 그 사실을 적습니다.
- 단위는 파일이 적은 그대로 축에 표시합니다. 단위를 변환하지 않고, 다른 프로파일의 X 격자로 보간하지 않으며, X 방향으로 맞추거나 옮기지 않습니다.
- 레벨링은 `없음` 과 `직선 제거` 두 가지이며 기본은 `없음` 입니다. `없음` 은 저장된 높이 그대로이므로 측정마다 절대 높이가 다르게 보일 수 있습니다. `직선 제거` 는 프로파일마다 자신의 최소제곱 직선을 뺀 높이이며 저장된 값이 아닙니다. 적용 중인 방식을 차트 아래와 Z 축 이름에 표시합니다.
- 프로파일에서 step height, 깊이, 거칠기(Ra, Rq)를 다시 계산하지 않으며, 장비가 낸 `(nm)` 값과 비교하지 않습니다. 2D 맵 비교와 차이 맵, 규격 판정도 없습니다. 프로파일이 없는 장비(5EAP1501)에서는 안내 문구 하나만 표시합니다.
- 어느 카드에서든 측정을 고르면 다른 카드에서도 같은 측정이 강조됩니다.
- 측정별 요약은 Excel 로 내려받을 수 있습니다.
- `Excel 다운로드` 의 `이상 측정 조사 묶음` 은 조사할 측정과 그 근거를 한 파일로 받습니다. (2026-10-09 추가) 조사 대상은 화면이 이미 표시하는 측정입니다. 기준 범위 밖의 대상 측정과 FAILED·STOPPED 포인트가 있는 측정이며, 새 판정 규칙은 없습니다. 기준으로 고정한 측정은 범위 밖으로 세지 않습니다.
- 파일은 세 시트입니다. `요약` 은 장비, 생성 시각, 분석 조건, 기준 범위의 이름과 근거, Recipe 별 μ 와 범위를 적습니다. `측정 목록` 은 그룹의 모든 측정을 적고 조사 대상을 첫 열에 표시합니다. `이상 측정 포인트` 는 조사 대상의 선택한 블록 포인트 행과, 포인트별 비교의 그룹 평균(같은 Recipe) 대비 차이를 적습니다. 내용이 없는 시트는 만들지 않습니다.
- 그룹의 상세 조회가 모두 끝났고 조사 대상이 1건 이상일 때만 받을 수 있습니다. 불러오지 못한 측정은 파일에 넣지 않고 요약에 건수로 적습니다.
- 포인트 기준은 화면의 02 포인트별 비교가 쓰는 조건(FAILED · Valid FALSE 행 포함 또는 제외)을 그대로 따르며, 어느 조건인지 요약에 적습니다. 범위 밖 여부는 반올림 전 값으로 판정하고 수치는 소수 4자리로 적습니다. 받기 전에 메모를 적을 수 있으며, 메모는 파일에만 들어가고 저장되지 않습니다.
- 이 파일은 조사 기록이며 판정이 아닙니다. 수치는 생성 시각 기준이고, 기준 범위는 사용자가 고른 측정에서 계산한 참고 범위입니다. 이미지와 프로파일은 파일에 넣지 않습니다.

## 4. 팁 모니터링

장비에 쓰인 팁을 종류별로 묶어 상태를 판정합니다.

- 지금 장착된 팁과 그 팁의 판정, 마지막 측정 시각을 맨 위에 보여 줍니다.
- 팁마다 이상, 주의, 정상, 보류 중 하나로 판정하고 상태별 팁 수를 셉니다.
- 기준 범위는 같은 팁 종류의 Tip Width 중앙값 ± 3σ 입니다. σ 는 MAD 기반으로 구합니다. 화면이 측정값에서 스스로 계산한 참고 범위이며, 엔지니어가 정한 관리 한계나 규격이 아니므로 관리선·UCL·LCL 이라고 부르지 않습니다.
- 최근 측정 가운데 기준 범위 밖이 2건 이상이면 이상, 1건이면 주의, 없으면 정상입니다. 같은 종류의 측정 수가 모자라면 보류로 둡니다.
- Mileage 는 누적값이므로 판정에 쓰지 않습니다.
- Recipe 를 고르면 그 Recipe 의 측정만으로 기준 범위와 판정을 다시 계산합니다.
- 이상·주의인 팁만 골라 볼 수 있습니다.
- 팁을 고르면 Tip Width 추이, 이 팁으로 잰 Recipe, 이 팁의 측정 목록(Tip Width, Mileage, Approach, FAILED, 판정)이 나옵니다. 목록의 행에서 해당 측정 상세로 이동합니다.

## 5. 가동 현황

장비가 언제 얼마나 측정했는지를 봅니다. 기간은 7일, 30일, 전체 중에서 고릅니다.

- 요약: 측정 건수, 가동일, 가동일 하루당 평균 측정, Recipe 수, Lot 수, 측정 point 수, 미완료 측정 수
- 일별 측정 건수: 측정이 많은 Recipe 순으로 쌓은 막대 그래프
- 시간대별 측정: 날짜 × 시간대 히트맵
- 미완료·무효 측정: 일별 건수
- 선택한 날의 측정: 차트에서 날짜를 누르면 그날의 측정 목록이 나오고, 행을 누르면 측정 상세가 열립니다.

## 6. Recipe 현황

Recipe 를 기준으로 장비의 측정 이력을 정리합니다.

- 요약 타일로 목록을 좁힙니다: 최근 7일 안에 측정한 Recipe, 30일 넘게 측정이 없는 Recipe, 1회만 측정한 Recipe
- Recipe 목록: 측정 건수, 마지막 측정일, 처음 측정일, Lot 수, Point 수, 적재된 파일 종류, 최근 추이, 미완료 건수. 열 머리글로 정렬하고 Recipe 이름으로 검색합니다.
- Recipe 를 고르면 일별 측정 건수, 사용한 팁, 그 Recipe 의 측정 목록이 나옵니다. 목록의 행에서 측정 상세로 이동합니다.
