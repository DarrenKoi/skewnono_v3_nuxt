대시보드 /계열·FAB 선택 진입점. 계열별 장비 대수와 시스템 상태, 미연결 장비 이동. 데이터 반출 금지 경고를 이 한 곳에 둡니다.

앱 소개화면별 가이드와 앱 연혁을 담은 문서형 화면.
API 리스트외부에서 직접 호출할 수 있는 API 카탈로그. curl · python 예제 자동 생성, 토큰 발급 안내.
사용 통계누가 어떤 기능을 얼마나 쓰는지, 내 신원이 무엇으로 잡혔는지. 페이지 열람 비콘을 여기서 집계합니다.
세팅다크·라이트 모드, 기본 FAB, 차트 테마, API 토큰 발급·삭제.
사용자 확인인프라가 이름을 못 붙인 접속자의 사번·이름 입력. 로그인이 아닌 신고 신원이며 미검증 배지가 붙습니다.
단축 링크메신저·보고서에 붙은 짧은 코드를 분석 화면으로 되돌립니다.
운영 로그 관리자실패한 요청 추적. 레벨·건수 필터.
접근 권한 관리자X 로 시작하는 차단 사번의 예외 허용 관리와 차단 시도 목록.

7. 횡단 특징

FAB 선택은 대시보드와 좌측 사이드바가 같은 상태를 쓰고, 마지막 선택을 기억해 계열 루트로 들어오면 바로 이전 FAB 으로 갑니다. 다중 FAB 선택이 기능 탭 이동에도 유지됩니다.

신원은 사내 세션 쿠키가 정본이며 토큰 → 쿠키 → 신고 → 로컬 → 익명 순으로 결정됩니다.

공지 배너가 모든 화면 상단에 뜨고, 표 다운로드는 하나의 공용 Excel 내보내기로 통일되어 있습니다.

사내 전환은 기능별 office 어댑터 파일의 존재만으로 켜지며, 코드 변경 없이 설정만으로 mock → 사내 localhost → 사내 클라우드를 오갑니다.

8. 2027 확장

VeritySEM 과 Provision 장비 리스트 화면은 자리표시자로 이미 라우팅되어 있고, AFM 4개 화면(장비 선택 · 측정 검색 · 측정 상세 · 시계열 비교)은 플래그로 숨겨진 채 코드가 준비되어 있습니다. Thickness 는 안내 화면만 있습니다. 장기적으로는 조회·시각화를 넘어 분석 전문 AI Agent 로 발전시키는 것이 목표입니다.
