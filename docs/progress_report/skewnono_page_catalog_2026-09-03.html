SKEWNONO v3 · 2026-09-03

SKEWNONO v3 화면별 기능 요약

CD-SEM 330대와 HV-SEM 60대, 합계 390대의 E-Beam 계측 장비를 한 서비스에서 관리하고 분석하는 플랫폼입니다. 이미 배포되어 현업에서 활용 중입니다.

1. 개발 규모와 방식

V2 는 약 5천 줄 규모의 CD-SEM 전용 서비스였습니다. V3 는 Vibe Coding 과 Harness Engineering 으로 비전문 개발자 1인이 5개월 만에 만들었습니다.

20만 줄코드 (Python · Vue · TypeScript)
5개월개발 기간 (2026년 5월 ~ 9월)
6.6만 줄자동 테스트 (백엔드 약 3,600건)
7.4만 줄문서
Python10.7만
Vue5.0만
TypeScript4.9만
V2 전체약 5천

개발자 1인이 6개월에 약 1만 줄을 쓴다는 통념과 견주면 10배가 넘는 산출입니다. 코드만 늘어난 것이 아니라 테스트와 문서가 같이 늘어난 점이 이 방식의 특징입니다.

3. 장비 운영 화면 CD-SEM · HV-SEM 공통

장비 상태

  • 접근 가능한 장비가 무엇이고 몇 대가 살아 있는지 확인합니다.
  • 장비 ID · 모델 · IP 검색, 가용성 칩 클릭 필터, Excel 다운로드.
  • 1시간마다 갱신됩니다.

스토리지 용량

  • 장비 디스크가 차서 측정이 막히기 전에 잡습니다.
  • 용량 테이블, 검색, 요약 통계. 매일 새벽 갱신됩니다.

Recipe 현황

  • Recipe 별 TAT 와 Align · 측정 실패를 한 화면에서 봅니다.
  • 일별 추이 차트, 랭킹, 장비 비교, Excel 다운로드.
  • 옛 Recipe TAT 와 Fail Issue 두 화면을 하나로 합쳤습니다.

Recipe 검색

  • 이름 조각만 알아도 Recipe 를 찾아 상세로 들어갑니다.
  • 여러 FAB 동시 검색, 최근 검색어, 다중 선택 후 비교.
  • 열어보기 · 횡전개 · 측정 이력 · 비교 4개 상세 화면으로 이어집니다.
    • 열어보기: 시퀀스 · 측정 위치 · Align 이미지를 펼쳐 봅니다. 십자선 오버레이가 기본으로 켜져 있습니다.
    • 횡전개: 같은 Recipe 가 어느 장비 · FAB 에 어떤 버전으로 퍼져 있는지 봅니다.
    • 측정 이력: 언제 어디서 얼마나 측정됐는지 봅니다.
    • 비교: 여러 Recipe 의 파라미터와 설정 차이를 나란히 봅니다.

H/W 관리

  • 장비 하드웨어 지표가 정상 범위인지 점검합니다.
  • FDC · Sharpness · BM/PM · BSM · Reso Center · MDC · SCE 7개 섹션.
  • 장비 간 편차 원인을 찾는 TTTM 개선 근거로 씁니다.
