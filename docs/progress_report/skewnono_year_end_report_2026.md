# SKEWNONO 2026년 성과 보고

작성일: 2026-10-09

## 1. 요약

스큐노노는 2026년에 E-Beam 계측 장비 조회 도구에서 현업이 매일 쓰는 계측 업무
서비스로 자리를 잡았습니다. 일평균 접속자는 60~70명입니다.

| 성과 | 사용 조직 | 내용 |
| --- | --- | --- |
| 디바이스 통계 | 검/계측 효율화 TF | 계측 파라미터와 포인트를 추적 · 분석할 수 있는 유일한 수단입니다. 전체 계측 시간을 10% 줄였습니다. |
| 실시간 알람 | 인라인 교대 구성원 | Align Fail 발견 시간이 최대 4~5분에서 10초 이내로 줄었습니다. |
| Recipe · 통계 · 결과 통합 조회 | 공정 · 소자 엔지니어 | Recipe 정보, 통계, 결과 데이터를 한 서비스에서 함께 봅니다. |
| AFM 관리 툴 | AFM 사용자 | AFM 측정 조회와 관리를 스큐노노로 통합했습니다. |

## 2. 검/계측 효율화 TF 지원: 디바이스 통계

### 배경

회사는 검/계측 효율화 TF 를 운영하고 있습니다. 효율화를 하려면 디바이스마다
어떤 계측 파라미터를 몇 포인트 재고 있는지부터 알아야 하는데, 이를 추적하고
분석할 수 있는 수단은 현재 스큐노노의 디바이스 통계 탭이 유일합니다.

### 제공한 것

CD 계측 효율화 담당 엔지니어의 요구사항을 반영해 대시보드와 분석 기능을
제공했습니다.

- 디바이스별 계측 활동을 랭킹과 Top-N 으로 보여 주고, 여러 디바이스를 골라
  나란히 비교합니다.
- 합의된 계측 룰을 화면에서 열람하고, 디바이스의 실제 계측이 그 룰에 맞는지
  판정합니다.
- lot health 신호등으로 파라미터 종류별 상한 대비 위반 비율을 빨강 · 노랑 ·
  초록으로 보여 주어 살펴볼 lot 을 바로 고를 수 있습니다.
- 주차별 스냅샷을 매주 자동으로 쌓아 계측량의 추세를 봅니다.
- 화면의 결과는 Excel 로 내려받아 TF 보고 자료로 씁니다.

### 성과

- 수만 개의 Recipe 가운데 과도하게 측정하는 Recipe 가 전부 모니터링되면서
  계측 포인트를 감축했습니다.
- 계측 포인트를 줄여 전체 계측 시간을 10% 단축했습니다. (계측 효율화 10% 달성)
- 모든 디바이스가 표준에 맞게 계측을 진행할 수 있게 되었습니다.

### 진행 중: 디바이스명 설명 스크립트 표준화

디바이스 통계는 디바이스 description 에서 제품군(Pool제 여부)과 개발 단계(t-EV,
PV 등)를 읽어 어떤 계측 룰을 적용할지 정합니다. 그런데 t-EV, PV, Pool제 같은
표기만으로는 확인이 어려운 디바이스 description 이 있어 판정이 흔들립니다. 이런
description 에 스큐노노의 로직에 맞는 표준화를 적용하고 있습니다.

## 3. 인라인 교대 지원: 실시간 알람

### 바뀐 점

| 구분 | 이전 | 현재 |
| --- | --- | --- |
| 확인 수단 | RCS CCTV 화면 | 스큐노노 실시간 알람 페이지 |
| 확인 방식 | 매번 많은 장비의 CCTV 를 하나씩 봅니다. | Align Fail 이 발생하면 피드에 바로 올라옵니다. |
| 발견까지 걸리는 시간 | 늦으면 4~5분 | 10초 이내 |
| 구성원 부담 | 여러 화면을 계속 지켜보아야 해 정신적 피로가 쌓입니다. | 알람이 온 장비만 확인합니다. |
| 장비 상태 파악 | 장비별로 따로 확인합니다. | 한 페이지에서 곧바로 파악합니다. |

### 사용 현황

인라인 교대 구성원이 상시 접속해 실시간으로 Align Fail 을 보고 작업을
진행합니다.

### 제공 기능

- CD-SEM 과 HV-SEM 의 Align 실패와 측정 실패를 최근 20분 피드로 보여 줍니다.
- 새로 도착한 알람을 강조하고, 미확인 건수를 브라우저 탭 제목에 표시합니다.
- 알람에서 바로 Align 이미지를 열어 십자선 오버레이와 함께 확인합니다.

## 4. 공정 · 소자 엔지니어 활용: Recipe · 통계 · 결과 통합 조회

스큐노노에서는 Recipe 정보, 통계 정보, 결과 데이터를 함께 볼 수 있습니다. 이
때문에 공정 · 소자 엔지니어가 많이 사용하고 있습니다.

| 보는 것 | 화면 | 내용 |
| --- | --- | --- |
| Recipe 정보 | Recipe 검색 | 열어보기, 횡전개, 측정 이력, 비교 |
| 통계 정보 | Recipe 현황, 디바이스 통계 | Recipe 별 TAT, Align · 측정 실패 추이, 디바이스별 계측 활동 |
| 결과 데이터 | 스큐보아 | 측정 세트를 웨이퍼 맵, 시계열, 상관, 이미지로 분석 |
| 장비 상태 | 장비 상태, 스토리지 용량, H/W 관리 | 가용 장비, 디스크 용량, 하드웨어 지표 |

## 5. AFM 관리 툴: Metrology Workspace 를 향해

AFM 관리 툴을 구현해 기존 AFM 조회 페이지를 스큐노노로 통합했습니다. E-Beam
계측에 이어 AFM 까지 한 서비스에 담으면서, 스큐노노는 Metrology Workspace
통합 서비스에 한발 더 가까워졌습니다.

대상 장비는 MAP608(PKG), MAPC01(R3), 5EAP1501(M15) 세 대입니다.

| 탭 | 내용 |
| --- | --- |
| 측정 결과 | 측정 검색, 측정 상세(포인트 요약, 분석 이미지, 프로파일), 시계열 비교 |
| 팁 모니터링 | 팁별 상태 판정과 Tip Width 추이 |
| 가동 현황 | 일별 · 시간대별 측정 건수 |
| Recipe 현황 | Recipe 별 측정 이력 |

화면별 상세는 [AFM 페이지 제공 기능 요약](../afm/feature-summary.md)에 있습니다.

## 6. 사용 현황

- 일평균 접속자는 60~70명입니다.
- 주 사용자는 인라인 교대 구성원, 공정 · 소자 엔지니어, 검/계측 효율화 TF 의 CD
  계측 담당 엔지니어입니다.

## 7. 이후 과제

- 디바이스명 설명 스크립트 표준화를 마무리해 디바이스 통계의 룰 판정을
  안정시킵니다.
- VeritySEM · Provision · Thickness 로 지원 장비를 넓혀 Metrology Workspace
  통합을 이어 갑니다.
