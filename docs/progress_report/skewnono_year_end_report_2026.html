2. 검/계측 효율화 TF 지원: 디바이스 통계

회사는 검/계측 효율화 TF 를 운영하고 있습니다. 효율화를 하려면 디바이스마다 어떤 계측 파라미터를 몇 포인트 재고 있는지부터 알아야 하는데, 이를 추적하고 분석할 수 있는 수단은 현재 스큐노노의 디바이스 통계 탭이 유일합니다.

제공한 것

CD 계측 효율화 담당 엔지니어의 요구사항을 반영해 대시보드와 분석 기능을 제공했습니다.

  • 디바이스별 계측 활동을 랭킹과 Top-N 으로 보여 주고, 여러 디바이스를 골라 나란히 비교합니다.
  • 합의된 계측 룰을 화면에서 열람하고, 디바이스의 실제 계측이 그 룰에 맞는지 판정합니다.
  • lot health 신호등으로 파라미터 종류별 상한 대비 위반 비율을 빨강 · 노랑 · 초록으로 보여 주어 살펴볼 lot 을 바로 고를 수 있습니다.
  • 주차별 스냅샷을 매주 자동으로 쌓아 계측량의 추세를 봅니다.
  • 화면의 결과는 Excel 로 내려받아 TF 보고 자료로 씁니다.

성과

전체 계측 시간 10% 단축
  • 수만 개의 Recipe 가운데 과도하게 측정하는 Recipe 가 전부 모니터링되면서 계측 포인트를 감축했습니다.
  • 계측 포인트를 줄여 전체 계측 시간을 10% 단축했습니다. (계측 효율화 10% 달성)
  • 모든 디바이스가 표준에 맞게 계측을 진행할 수 있게 되었습니다.

디바이스명 설명 스크립트 표준화

진행 중

디바이스 통계는 디바이스 description 에서 제품군(Pool제 여부)과 개발 단계(t-EV, PV 등)를 읽어 어떤 계측 룰을 적용할지 정합니다. 그런데 t-EV, PV, Pool제 같은 표기만으로는 확인이 어려운 디바이스 description 이 있어 판정이 흔들립니다. 이런 description 에 스큐노노의 로직에 맞는 표준화를 적용하고 있습니다.

5. AFM 관리 툴: Metrology Workspace 를 향해

AFM 관리 툴을 구현해 기존 AFM 조회 페이지를 스큐노노로 통합했습니다. E-Beam 계측에 이어 AFM 까지 한 서비스에 담으면서, 스큐노노는 Metrology Workspace 통합 서비스에 한발 더 가까워졌습니다.

대상 장비는 MAP608(PKG), MAPC01(R3), 5EAP1501(M15) 세 대입니다.

6. Metrology 엔지니어 지원: FTP 접속

2026-10-20 에 장비 상태 아래 FTP 접속 탭을 열었습니다. 장비 파일을 보려면 그동안 별도 FTP 프로그램으로 장비마다 접속해야 했습니다. 이제 CD-SEM · HV-SEM 장비를 고르면 장비의 폴더와 파일을 스큐노노에서 바로 엽니다.

구분내용
대상DRAM MI개발, NAND MI개발, DRAM Metrology기술, NAND Metrology기술, 기반기술전략
탐색폴더를 눌러 이동하거나 경로를 직접 입력합니다. 폴더와 파일은 아이콘 색으로 구분합니다.
다운로드파일을 하나씩 받거나, 여러 개를 골라 zip 한 개로 받습니다. 용량 상한은 화면에 표시됩니다.
공유주소에 장비와 경로가 함께 담겨 링크로 같은 폴더를 공유합니다.
안정성동시 다운로드와 FTP 세션 수를 제한해 장비 접속이 몰려도 서비스가 느려지지 않습니다.

장비 리스트의 파일 열기 버튼은 이 탭으로 옮겼습니다. 업로드 · 삭제 기능은 구현을 마쳤지만 꺼 둔 상태입니다.

7. 데이터 정확도 개선 (10월)

보고 이후 현업 문의를 바탕으로 화면이 보여 주는 값의 정확도를 높였습니다.

  • 디바이스 통계: 저장된 필터가 목록을 좁히고 있으면 표시하고, 원본에 스텝이 없는 디바이스는 "스텝 원본 자료 없음" 으로 따로 알립니다. R 계열 디바이스 일부에서 DRAM / NAND 구분이 빠지던 문제를 고쳤습니다.
  • Recipe 횡전개: 장비별 Recipe 보유 · 버전 원본(IDP 버전 이력)의 오류를 바로잡아, 최근에 측정하지 않은 장비도 보유로 표시되고 버전이 갈린 장비가 드러납니다. 점검에 실패한 장비는 "확인 불가" 로 구분합니다.
  • Recipe 현황: 이력이 많은 조회에서 결과 일부가 빠지거나 응답이 끊기던 문제를 고쳤습니다.
  • AFM: 측정 목록 응답에서 화면이 쓰지 않는 파일 목록을 빼, 이력이 쌓여도 화면이 느려지지 않습니다.
  • 운영: 요청 로그에 오류 원인과 호출 화면을 함께 남겨 문의 대응 시간을 줄였습니다.

9. 이후 과제

  • 디바이스명 설명 스크립트 표준화를 마무리해 디바이스 통계의 룰 판정을 안정시킵니다.
  • VeritySEM · Provision · Thickness 로 지원 장비를 넓혀 Metrology Workspace 통합을 이어 갑니다. VeritySEM · Provision 은 사내 데이터 사전 조사를 시작했습니다.
