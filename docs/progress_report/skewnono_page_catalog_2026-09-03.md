# SKEWNONO v3 화면별 기능 요약 (임원 보고용, 2026-09-03)

## 1. 한 줄 요약

SKEWNONO v3 는 CD-SEM 약 270대와 HV-SEM 약 50대, 합계 약 320대의 E-Beam 계측
장비의 운영 정보·Recipe·하드웨어 상태·측정 데이터를 한 서비스에서 관리하고
분석하는 플랫폼입니다. 화면은 크게 **장비 운영 6종**, **분석 3종**, **실험실 4종**,
**공통·관리 8종** 으로 구성됩니다.

## 2. 개발 규모와 방식

V2 는 약 5천 줄 규모의 CD-SEM 전용 서비스였습니다. V3 는 Vibe Coding 과 Harness
Engineering(에이전트가 따를 규칙·테스트·검증 게이트를 먼저 설계하는 방식)으로
개발되어, 비전문 개발자 1인이 아래 규모의 코드베이스를 만들었습니다.

전통적으로 개발자 1인이 6개월에 약 1만 줄을 작성한다는 통념과 비교하면
(업계 통념이며 출처 검증 값은 아님), 같은 기간 대비 10배 이상의 산출이 나온
사례입니다. 줄 수는 그 자체가 품질은 아니지만, 테스트 6.6만 줄과 문서 7.4만
줄이 함께 늘어난 점이 이 방식의 특징입니다. 즉 코드가 늘어난 만큼 검증과
기록도 같이 늘었습니다.

## 4. 장비 운영 화면 (CD-SEM · HV-SEM 공통)

### 장비 상태

- 목적: 스큐노노가 접근 가능한 장비가 무엇이고 몇 대가 살아 있는지 확인합니다.
- 기능: 장비 리스트 테이블, 장비 ID·모델·IP 통합 검색, 가용성 통계 칩 클릭 필터, Excel 다운로드.
- 특징: 1시간 주기 갱신. 통계 칩이 곧 필터라 클릭 한 번으로 문제 장비만 남깁니다.
- 데이터: 사내 Redis (사내 실검증 완료).

### 스토리지 용량

- 목적: 장비 디스크가 가득 차서 측정이 막히기 전에 잡습니다.
- 기능: 용량 테이블, 검색, 요약 통계, PPID 미가용 조회.
- 특징: 매일 04:30 갱신. 장비 상태의 형제 탭으로 왕복합니다.
- 데이터: 사내 Redis (사내 실검증 완료).

### Recipe 현황

- 목적: Recipe 별 TAT 와 Align·측정 실패를 한 화면에서 봅니다.
- 기능: TAT / Align 실패 / 측정 실패 3탭, 일별 추이 차트, 랭킹 테이블, 장비 비교, "오늘 데이터" 포함 토글, Excel 다운로드.
- 특징: 옛 Recipe TAT 와 Fail Issue 두 화면을 통합했습니다. 탭 전환 시 필터와 테이블 상태가 보존되며 탭이 URL 에 실려 딥링크가 됩니다.
- 데이터: 사내 OpenSearch 측정 이력 인덱스.

### Recipe 검색

- 목적: 이름 조각만 아는 Recipe 를 찾아 상세로 들어갑니다.
- 기능: 토큰화 검색과 랭킹, 최근 검색어, 다중 FAB 동시 검색, 레지스트리 확인, 다중 선택 후 비교.
- 특징: 레지스트리에 없는 Recipe 는 OpenSearch 대체 결과로 표시하고 비교 불가를 화면이 명시합니다.
- 데이터: 장비 FTP (프록시 경유) + OpenSearch.

### Recipe 열어보기 · 횡전개 · 측정 이력 · 비교

- 열어보기: Recipe 파일의 시퀀스·측정 위치·AMP 섹션을 펼치고 Align 이미지를 라이트박스로 봅니다. cond.txt 기반 십자선 오버레이가 기본 켜져 있습니다. 이미지와 설정을 묶어 다운로드합니다.
- 횡전개: 같은 Recipe 가 어느 장비·FAB 에 어떤 버전으로 퍼져 있는지 버전별로 묶어 보여 줍니다.
- 측정 이력: 그 Recipe 가 언제 어디서 얼마나 측정되었는지 테이블로 봅니다.
- 비교: 고른 Recipe 들의 파라미터와 측정 설정 차이를 나란히·분포로 비교합니다.
- 데이터: 장비 FTP, 사내 이미지 캐시(MinIO), OpenSearch.

### H/W 관리

- 목적: 장비 하드웨어 지표가 정상 범위인지 서비스별로 점검합니다.
- 기능: FDC · Sharpness · BM/PM · BSM · Reso Center · MDC · SCE 7개 섹션, 모델 → 장비 2단 선택, 축 범위 조절, 장비 비교, BM/PM 표시 토글.
- 특징: 섹션마다 사내 소스가 다릅니다. 레이더·추세·프로파일 차트를 혼합해 장비 간 편차 원인을 찾는 TTTM 개선 근거로 씁니다.
- 데이터: OpenSearch 하드웨어 인덱스 여러 종 + Redis·MinIO 보조.

## 5. 분석 화면

### 스큐보아 (검색 + 분석 워크스페이스)

- 목적: 분석할 측정 세트를 조건으로 찾아 여러 관점으로 파고들어 스큐 원인을 좁힙니다.
- 기능: 검색바·패싯 필터·날짜 범위, 선택 워크벤치, 분석 6개 뷰(Dashboard · Position Stack · FDC · Time Series · Correlation · Gallery), 웨이퍼 맵·히트맵·상관 산점도·이미지 라이트박스, Excel 내보내기.
- 특징: 활성 뷰·축·기준선이 URL 에 실려 단축 링크로 공유됩니다. 보존 기간 밖 데이터와 결과 상한을 화면 스트립으로 항상 알립니다.
- 데이터: OpenSearch 측정 이력 + MinIO 측정 파일 + 장비 FTP 이미지.

### 디바이스 통계 · 디바이스 비교 · 측정 규칙 (CD-SEM)

- 목적: 디바이스별 측정 활동이 합의된 계측 룰 대비 정상인지, 어느 lot 을 파봐야 하는지 판정합니다.
- 기능: FAB 선택, 디바이스 그룹·측정 활동 랭킹, Top-N, 테이블·카드 뷰, 다중 선택 후 비교, Excel 다운로드와 클립보드 복사. 비교 화면은 lot 상세 모달·규칙 준수 테이블·스택 막대를 제공합니다. 측정 규칙 화면은 룰 매트릭스를 봅니다.
- 특징: lot health 신호등. 파라미터 종류(WAFER/LEVEL/EDGE/EDGE_EX)별 상한으로 위반 recipe 비율을 계산해 빨강·노랑·초록으로 표시합니다. 룰이 없는 M 계열 FAB 은 회색으로 두어 "색 없음"을 "정상"과 구분합니다.
- 데이터: Redis + FTP + MinIO (다섯 함수 모두 사내 소스 대상 작성 완료).

## 6. 실험실 (BETA)

### 라이브 알람

- 목적: 지금 이 순간 Align 실패·측정 실패가 어디서 나는지 봅니다.
- 기능: 최근 20분 알람 피드, 종류 필터, 신규 도착 행 강조, 미확인 카운트를 브라우저 탭 제목에 표시, Align 이미지 모달(십자선 포함).
- 특징: 15초 폴링에 지터를 두어 여러 탭이 동시에 요청하지 않게 합니다.
- 데이터: 사내 Redis.

### 장비간 스큐 (TTTM) · PM 튜닝

- 목적: 같은 셀을 측정하는 장비 중 어느 조합이 서로 잘 맞는지 추천하고, 어느 장비를 PM 으로 맞출지 정합니다.
- 기능: Recipe 스코프 선택, 모델 그룹별 비교 장비 선택, 수집 기간, 분석 패널 5종(그룹 판정 · 배치도 · 장비쌍 행렬 · 추세 · PM 튜닝).
- 특징: tolerance 슬라이더로 판정 민감도를 nm 와 배수로 동시에 조정합니다. 한 번의 요청으로 모든 패널을 계산합니다. 추정기가 아직 미검증이라 실험실에 둡니다.
- 데이터: Redis · MinIO · FTP + OpenSearch.

### Mag/Pixel 가이드

- 목적: 패턴이 시야(FOV) 안에 들어오는 한도에서 쓸 수 있는 최대 배율·픽셀 조합을 계산합니다.
- 특징: 서버 호출 없는 순수 계산기. 첫 화면에 예시값이 채워져 있습니다.

### 채팅 (RAG)

- 목적: 스큐노노가 가진 데이터와 사내 문서에 대해 자연어로 묻습니다.
- 기능: 스레드 관리, 인용·그림 렌더, 좋아요·싫어요 피드백, 실패 turn 재시도.
- 특징: 답변 생성을 서버 작업으로 다루어 새로고침해도 진행 중 답변을 이어받습니다. 한국어·영어를 한 요청에서 함께 검색합니다.
- 데이터: OpenSearch + MinIO RAG 저장소, 사내 LLM 게이트웨이.

## 8. 횡단 특징

- FAB 선택은 대시보드와 좌측 사이드바가 같은 상태를 쓰고, 마지막 선택을 기억해 계열 루트로 들어오면 바로 이전 FAB 으로 갑니다. 다중 FAB 선택이 기능 탭 이동에도 유지됩니다.
- 신원은 사내 세션 쿠키가 정본이며 토큰 → 쿠키 → 신고 → 로컬 → 익명 순으로 결정됩니다.
- 모든 화면 상단에 공지 배너가 뜨고, 표 다운로드는 하나의 공용 Excel 내보내기로 통일되어 있습니다.
- 사내 전환은 기능별 `providers/office.py` 파일의 존재만으로 켜지며, 코드 변경 없이 설정만으로 mock → 사내 localhost → 사내 클라우드를 오갑니다.

## 9. 2027 확장

VeritySEM 과 Provision 장비 리스트 화면은 자리표시자로 이미 라우팅되어 있고, AFM 4개 화면(장비 선택 · 측정 검색 · 측정 상세 · 시계열 비교)은 플래그로 숨겨진 채 코드가 준비되어 있습니다. Thickness 는 안내 화면만 있습니다. 장기적으로는 조회·시각화를 넘어 분석 전문 AI Agent 로 발전시키는 것이 목표입니다.
