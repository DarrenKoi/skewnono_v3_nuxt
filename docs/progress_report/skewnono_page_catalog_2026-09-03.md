# SKEWNONO v3 화면별 기능 요약 (2026-09-03)

## 1. 한 줄 요약

CD-SEM 330대와 HV-SEM 60대, 합계 390대의 E-Beam 계측 장비를 한 서비스에서
관리하고 분석하는 플랫폼입니다. 이미 배포되어 현업에서 활용 중입니다.

## 2. 개발 규모와 방식

V2 는 약 5천 줄 규모의 CD-SEM 전용 서비스였습니다. V3 는 Vibe Coding 과 Harness
Engineering 으로 비전문 개발자 1인이 5개월 만에 만들었습니다.

| 항목 | 값 |
| --- | --- |
| 개발 기간 | 2026년 5월 ~ 9월 (5개월) |
| 코드 | 약 20만 줄 (Python 10.7만, Vue 5.0만, TypeScript 4.9만) |
| 자동 테스트 | 약 6.6만 줄 (백엔드 약 3,600건) |
| 문서 | 약 7.4만 줄 |
| V2 전체 | 약 5천 줄 |

개발자 1인이 6개월에 약 1만 줄을 쓴다는 통념과 견주면 10배가 넘는 산출입니다.
코드만 늘어난 것이 아니라 테스트와 문서가 같이 늘어난 점이 이 방식의 특징입니다.

## 4. 장비 운영 화면 (CD-SEM · HV-SEM 공통)

### 장비 상태

- 접근 가능한 장비가 무엇이고 몇 대가 살아 있는지 확인합니다.
- 장비 ID · 모델 · IP 검색, 가용성 칩 클릭 필터, Excel 다운로드.
- 1시간마다 갱신됩니다.

### 스토리지 용량

- 장비 디스크가 차서 측정이 막히기 전에 잡습니다.
- 용량 테이블, 검색, 요약 통계. 매일 새벽 갱신됩니다.

### Recipe 현황

- Recipe 별 TAT 와 Align · 측정 실패를 한 화면에서 봅니다.
- 일별 추이 차트, 랭킹, 장비 비교, Excel 다운로드.
- 옛 Recipe TAT 와 Fail Issue 두 화면을 하나로 합쳤습니다.

### Recipe 검색

- 이름 조각만 알아도 Recipe 를 찾아 상세로 들어갑니다.
- 여러 FAB 동시 검색, 최근 검색어, 다중 선택 후 비교.
- 열어보기 · 횡전개 · 측정 이력 · 비교 4개 상세 화면으로 이어집니다.
  - 열어보기: 시퀀스 · 측정 위치 · Align 이미지를 펼쳐 봅니다. 십자선 오버레이가 기본으로 켜져 있습니다.
  - 횡전개: 같은 Recipe 가 어느 장비 · FAB 에 어떤 버전으로 퍼져 있는지 봅니다.
  - 측정 이력: 언제 어디서 얼마나 측정됐는지 봅니다.
  - 비교: 여러 Recipe 의 파라미터와 설정 차이를 나란히 봅니다.

### H/W 관리

- 장비 하드웨어 지표가 정상 범위인지 점검합니다.
- FDC · Sharpness · BM/PM · BSM · Reso Center · MDC · SCE 7개 섹션.
- 장비 간 편차 원인을 찾는 TTTM 개선 근거로 씁니다.

## 5. 분석 화면

### 스큐보아

- 측정 세트를 조건으로 찾아 여러 관점으로 파고들어 스큐 원인을 좁힙니다.
- Dashboard · Position Stack · FDC · Time Series · Correlation · Gallery 6개 뷰.
- 웨이퍼 맵, 히트맵, 상관 산점도, 이미지 라이트박스, Excel 내보내기.
- 보고 있던 화면 그대로를 단축 링크로 공유합니다.

### 디바이스 통계 (CD-SEM)

- 디바이스별 측정 활동이 합의된 계측 룰에 맞는지, 어느 lot 을 살펴야 하는지 판정합니다.
- 디바이스 랭킹, Top-N, 다중 선택 비교, 측정 규칙 열람, Excel 다운로드.
- lot health 신호등: 파라미터 종류별 상한으로 위반 비율을 계산해 빨강 · 노랑 · 초록으로 보여 줍니다.

## 6. 실험실 (BETA)

### 라이브 알람

- 지금 이 순간 Align 실패 · 측정 실패가 어디서 나는지 봅니다.
- 최근 20분 피드, 신규 도착 강조, 미확인 건수를 브라우저 탭 제목에 표시, Align 이미지 모달.
- 교대 여사원들이 적극 사용 중입니다.

### 장비간 스큐 (TTTM) · PM 튜닝

- 같은 셀을 재는 장비 중 어느 조합이 서로 잘 맞는지 추천하고 어느 장비를 PM 으로 맞출지 정합니다.
- 그룹 판정 · 배치도 · 장비쌍 행렬 · 추세 · PM 튜닝 5개 패널.
- tolerance 슬라이더로 판정 민감도를 조정합니다.

### Mag/Pixel 가이드

- 패턴이 시야 안에 들어오는 한도에서 쓸 수 있는 최대 배율 · 픽셀 조합을 계산합니다.

### 채팅

- 스큐노노 데이터와 사내 문서에 대해 자연어로 묻습니다.
- 답변 근거 인용, 그림 표시, 좋아요 · 싫어요 피드백.
