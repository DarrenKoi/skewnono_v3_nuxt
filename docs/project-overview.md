# SKEWNONO v3 프로젝트 소개

## 프로젝트 개요

SKEWNONO v3는 반도체 E-Beam 계측 장비의 운영 정보와 측정 데이터를 한곳에서
관리하고 분석하는 통합 플랫폼입니다. 기존 SKEWNONO v2의 CD-SEM 중심 기능을
확장하여 CD-SEM과 HV-SEM을 함께 지원하며, 장비 상태와 레시피 파라미터를 더
체계적으로 관리하는 것을 목표로 합니다.

SKEWNONO v2는 약 270대의 CD-SEM만을 대상으로 서비스했습니다. SKEWNONO v3는
기존 CD-SEM 약 270대에 HV-SEM 약 50대를 추가하여 총 약 320대의 장비를 하나의
서비스에서 관리할 수 있도록 범위를 넓혔습니다.

SKEWNONO v3는 **2026년 7월 말 오픈**을 목표로 구축하고 있습니다.

## v2와 v3의 차이

| 구분 | SKEWNONO v2 | SKEWNONO v3 |
| --- | --- | --- |
| 지원 장비 | CD-SEM | CD-SEM, HV-SEM |
| 대상 장비 수 | 약 270대 | 약 320대(CD-SEM 약 270대 + HV-SEM 약 50대) |
| 주요 범위 | CD-SEM 중심 운영 정보 제공 | E-Beam 장비 통합 관리와 데이터 분석 |
| 장비 데이터 | 제한적인 장비 정보 활용 | 주요 하드웨어 상태와 캘리브레이션 데이터 통합 |
| 파라미터 관리 | 측정 이력이 있는 Recipe 중심의 추적 | Device Statistics 기능 강화 및 전사 전체 Recipe 추적 구조 구축 |
| 데이터 분석 | 개별 기능 중심의 데이터 확인 | Skewvoir 통합 데이터 분석 대시보드 구축 |

## 핵심 기능

### 1. CD-SEM 및 HV-SEM 통합 관리

CD-SEM과 HV-SEM의 장비 목록, 상태, 레시피 및 운영 정보를 공통된 화면과 데이터
구조로 제공합니다. 사용자는 장비 유형과 Fab을 기준으로 필요한 정보를 빠르게
조회하고, 여러 시스템에 흩어진 장비 정보를 하나의 서비스에서 확인할 수 있습니다.

### 2. 하드웨어 및 캘리브레이션 데이터 활용

장비에서 중요한 하드웨어 상태 정보와 캘리브레이션 데이터를 추출하여 시계열과
장비 간 비교 관점으로 분석합니다. 이를 통해 장비별 상태 변화와 보정값의 차이를
파악하고, 측정 편차의 원인을 더 구체적으로 확인할 수 있습니다.

이 데이터는 Tool-to-Tool Matching(TTTM)을 개선하기 위한 근거로 활용합니다. 단순히
측정 결과만 비교하는 것이 아니라, 장비 상태와 캘리브레이션 이력을 함께 살펴봄으로써
장비 간 차이를 더 정확하게 이해하고 관리할 수 있도록 지원합니다.

### 3. Device Statistics 기반 파라미터 관리

SKEWNONO v3에서는 기존 Device Statistics 기능을 대폭 강화합니다. DRAM, NAND,
New Memory를 구분하여 조회할 수 있으며, Device별로 데이터를 나누어 각 CD Step의
Parameter 현황을 세부적으로 검토할 수 있습니다.

주요 제공 범위는 다음과 같습니다.

- DRAM, NAND, New Memory별로 Device와 Recipe 현황을 구분하여 확인합니다.
- Device별 CD Step과 Parameter 구성 및 분포를 검토합니다.
- lot별 운영 Recipe 수와 Parameter 분포를 확인합니다.
- 여러 lot의 Recipe 및 Parameter 현황을 비교합니다.
- 기간별 변화와 추세를 분석합니다.
- 공정·소자·MI가 합의한 계측 룰을 공통 관리 기준으로 적용합니다.
- 계측 룰을 벗어난 Recipe와 Parameter의 위반 정도를 Device별로 추적합니다.
- 과도하거나 불필요한 측정 항목을 찾아 레시피 최적화를 지원합니다.

합의된 계측 룰을 기준으로 각 Device의 Recipe와 Parameter 구성을 평가하고, 룰 위반
Recipe의 비율과 변화 추이를 확인할 수 있습니다. 이를 통해 공정·소자·MI가 동일한
기준으로 관리가 필요한 Device를 식별하고 개선 결과를 지속해서 추적할 수 있습니다.

기존 시스템에서는 실제 측정 이력이 있는 Recipe만 추적할 수 있었습니다. v3에서는
측정 여부와 관계없이 전사에서 관리하는 모든 Recipe를 추적할 수 있도록 관련 코드를
재구축하고 있습니다. 이 작업이 완료되면 미사용·미측정 Recipe까지 관리 범위에
포함하여 Device와 CD Step 단위의 Parameter 현황을 더 완전하게 파악할 수 있습니다.

이를 통해 엔지니어는 Parameter를 일관된 기준으로 관리하고, 측정 품질을 유지하면서
불필요한 측정과 Turn-Around Time(TAT)을 줄일 수 있습니다.

### 4. 데이터 분석 대시보드(Skewvoir)

측정 데이터를 종합적으로 분석하는 대시보드인 Skewvoir도 함께 구축하고 있습니다.
Skewvoir는 개별 측정 결과, 장비 상태, 측정 실행 및 데이터 품질 정보를 연결하여
검토가 필요한 측정을 빠르게 식별하고 원인을 분석할 수 있도록 지원합니다.

주요 분석 범위는 다음과 같습니다.

- 개별 측정 결과와 주요 지표를 한눈에 확인합니다.
- 웨이퍼 위치별 분포와 장비·측정 간 차이를 비교합니다.
- 시간에 따른 측정값과 품질 변화를 추적합니다.
- Parameter 간 상관관계를 분석합니다.
- 측정 이미지와 상세 데이터를 함께 확인합니다.

이를 통해 사용자는 여러 시스템의 데이터를 개별적으로 확인하는 대신, 하나의
대시보드에서 이상 징후를 발견하고 세부 원인까지 단계적으로 분석할 수 있습니다.

## 기대 효과

- 약 320대의 CD-SEM 및 HV-SEM을 하나의 플랫폼에서 통합 관리할 수 있습니다.
- 장비 상태, 하드웨어 정보, 캘리브레이션 데이터와 측정 결과를 함께 분석할 수
  있습니다.
- 장비 간 편차의 원인을 빠르게 파악하여 TTTM 개선 활동을 지원합니다.
- Device Statistics를 통해 메모리 유형과 Device·CD Step별 Recipe 및 Parameter의
  표준화와 최적화를 지원합니다.
- 공정·소자·MI의 합의된 계측 룰을 기준으로 Device별 위반 정도와 개선 추이를
  일관되게 관리할 수 있습니다.
- 측정 이력에 한정되었던 관리 범위를 전사 전체 Recipe로 확장할 수 있습니다.
- Skewvoir를 통해 측정 결과와 장비 상태를 연결하여 데이터 검토와 원인 분석 시간을
  단축할 수 있습니다.
- 장비와 데이터가 추가되더라도 동일한 구조로 기능을 확장할 수 있습니다.

## 추진 목표

SKEWNONO v3는 CD-SEM과 HV-SEM 통합 관리, Device Statistics 기능 강화, 하드웨어 및
캘리브레이션 데이터 활용, Skewvoir 데이터 분석 대시보드 구축을 포함하여
**2026년 7월 말 오픈**을 목표로 추진하고 있습니다.

## 2027년 확장 계획

2027년에는 VeritySEM과 PROVision을 추가로 연계하고, Thickness 측정 장비까지
지원 범위를 확대할 계획입니다. 이를 통해 다양한 계측 장비의 운영 정보와 측정
데이터를 하나의 플랫폼에서 연결하여 분석할 수 있는 기반을 강화합니다.

또한 SKEWNONO를 단순한 데이터 조회·시각화 시스템에서 **분석 전문 AI Agent**
형태로 발전시킬 예정입니다. AI Agent가 장비, 측정, Recipe 및 Parameter 데이터를
종합적으로 분석하고, 사용자가 확인해야 할 이상 징후와 주요 검토 사항을 제안하여
엔지니어의 의사결정을 지원하는 것을 목표로 합니다.

## 한 문장으로 정리

SKEWNONO v3는 CD-SEM과 HV-SEM 약 320대의 운영 데이터, 주요 하드웨어 정보,
캘리브레이션 데이터, Recipe 및 Parameter를 통합하고 Skewvoir 분석 기능을 제공하여
장비 간 정합성과 계측 운영 효율을 높이는 E-Beam 계측 장비 관리·분석 플랫폼입니다.
