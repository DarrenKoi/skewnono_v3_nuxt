SKEWNONO v3 오픈 안내

CD-SEM · HV-SEM 약 320대의 운영 데이터와 계측 데이터를 하나로

안녕하십니까. 계측 장비 통합 관리·분석 플랫폼 SKEWNONO v3를 오픈하게 되어 안내드립니다.

기존 v2는 CD-SEM 약 270대만을 대상으로 했습니다. v3는 여기에 HV-SEM 약 50대를 추가하여 총 약 320대를 하나의 서비스에서 관리하며, 장비 상태·하드웨어·Recipe·Parameter·측정 데이터를 연결해 분석할 수 있도록 확장하였습니다.
 

주요 기능

01 CD-SEM · HV-SEM 통합 관리
장비 상태, Recipe 현황, Recipe 검색, H/W 관리를 장비 유형·Fab 기준의 동일한 화면에서 조회합니다.
02 하드웨어 · 캘리브레이션 데이터 분석
주요 하드웨어 상태와 보정값을 시계열·장비 간 비교로 확인하여 TTTM 개선의 근거로 활용합니다.
03 디바이스별 CD Step · Recipe 현황 대시보드
DRAM · NAND · New Memory 등 디바이스 카테고리별로 구분하여 CD Step과 Recipe · Parameter 현황을 검토하고 최적화할 수 있도록 대시보드를 제공합니다.
04 통합 분석 대시보드 '스큐보아(Skewvoir)'
측정 결과·장비 상태·데이터 품질을 연결하여 검토가 필요한 측정을 먼저 식별하고, 웨이퍼 분포·시계열·Parameter 상관·측정 이미지까지 단계적으로 원인을 분석합니다.
