# 03: 스토리지·장비 리스트에서 "파일 열기"로 진입

**What to build:** 장비 관리자가 `장비 상태`의 `스토리지` 표나 `장비 리스트` 표에서 장비 행의 "파일 열기"를 누르면, 그 장비의 탐색기가 바로 열립니다. URL을 직접 입력할 필요가 없어집니다.

**Blocked by:** 02 (관리자 전용 파일 탐색기)

**Status:** ready-for-agent

- [ ] 스토리지 표와 장비 리스트 표의 각 행에 "파일 열기" 액션을 둡니다
- [ ] 액션은 해당 행의 tool, fab, eqp_id로 탐색기 URL을 엽니다. 대상 장비는 서버가 sem_list에서 다시 해석합니다
- [ ] 스토리지 행에 남은 장비 정보가 이미 오래되어 서버 해석이 실패하면(404·409), 탐색기 화면에 그 이유를 표시합니다
- [ ] 액션은 권한과 관계없이 보입니다. 권한 판정은 탐색기 페이지가 합니다
- [ ] 기존 표의 레이아웃·정렬·필터 동작이 바뀌지 않습니다
- [ ] `browser-verify` 스킬로 두 표에서 진입하는 것을 각각 확인합니다
