# Handoff: 레시피 횡전개 — 이관됨 (2026-10-18)

Status: moved

이 설계는 SKEWNONO 기능이 아니라 **별도 web app**으로 확정되어
`https://github.com/DarrenKoi/bulk_recipe_copy` (로컬 `~/Codes/bulk_recipe_copy`)로
이관되었습니다. handoff r3, 검토 기록(r1), 사무실 요청 편지, 관련 datatables 사본이
그쪽 `docs/`에 있습니다. 여기서는 더 이상 갱신하지 않습니다.

SKEWNONO에 남는 일은 하나뿐입니다. 앱이 완성되면 상단 메뉴에 외부 링크("레시피
복사")를 답니다. `backend/` 아래에 feature 폴더를 만들지 않습니다.

사무실 확인 요청 `docs/office-migration/to-office-recipe-copy-261018.md`는 사무실이
이 저장소를 pull하므로 여기 둡니다. 회신이 오면 그 파일 끝에 기록한 뒤 새 repo의
`docs/office/` 사본에도 옮깁니다.
