예시 이 페이지의 모든 그래프·숫자는 조작된 예시 데이터입니다(실제 장비 수출 아님). 스펙트럼은 Cauchy 단일막 간섭식으로 이 페이지에서 직접 계산하고, 사이트·장비·날짜는 시드 고정 난수로 만듭니다. 원문은 docs/research/2026-10-24-optical-metrology-analysis-display.md 입니다.
요약

두께·엘립소미터 데이터는 스큐보아에 얹지 않고 AFM 이 걸었던 길(자기 도메인·feature 폴더·화면)을 갑니다. 스큐보아는 cd-sem·hv-sem 에만 열리도록 울타리가 쳐져 있고, MsrParamSummary 에는 파장 축이 없습니다. 권장 구성은 두 층입니다 — ① 시간·lot·eqp·recipe·site 축으로 파생값(두께·n·k) 비교, ② 모든 두께 숫자 옆에 적합 품질(MSE/χ², 잔차, 오차한계, 상관). 가장 큰 위험은 UI 가 아니라 근거의 부재입니다 — docs/datatables/ 에 두께·SE 소스가 하나도 없습니다.

§1 · 데이터 세 층

이 데이터는 실제로 무엇인가

광학 계측은 한 종류가 아니라 서로 다른 세 층입니다. 섞으면 화면이 거짓말을 합니다. 각 층을 눌러 펼칩니다.

RAW스펙트럼 — 각 파장·입사각(AOI)에서의 Ψ 와 Δ

측정되는 물리량은 ρ = rp/rs = tan(Ψ)·eiΔ 입니다. 일반화 엘립소메트리·뮬러 행렬 장비는 행렬 성분(m11..m33)과 탈편광이 더해집니다.

  • Ψ(λ, AOI), Δ(λ, AOI) — 곡선 하나는 AFM 프로파일과 구조적으로 같은 물건입니다(x = 위치 ↔ 파장, y = 높이 ↔ Ψ/Δ).
  • 취득 조건도 RAW 의 일부 — 파장 범위·분해능, 입사각, 방위각, 스팟/픽셀 크기·시야, 적분 시간, 평균 횟수.
  • 반사율계가 오면 측정량은 R(λ) 이 되고 모델·잔차 구조는 그대로입니다 → 계약은 "스펙트럼 + 모델 + 잔차" 로 둡니다.
  • Δ 는 360° 주기 — 잔차는 위상 래핑을 고려해서 계산해야 합니다(이 페이지의 데모가 그렇게 합니다).
DERIVED두께 · n · k · 적합 진단 — 측정값이 아니라 회귀 추정치

Cauchy(투명막), Tauc-Lorentz(흡수 비정질), Drude(금속), B-spline(KK 일관) 같은 분산 모델에 최소자승 회귀를 돌려 얻습니다. 그래서 반드시 함께 오는 것들이 있습니다.

핵심 데모 · B 방식 · §7-2

적합 품질 트랩 — MSE 숫자만으로는 (a) 와 (c) 를 구별하지 못합니다

Si 기판 위 단일 Cauchy 막, AOI 70°, 300–1000 nm(5 nm 간격). 측정 곡선은 "정답" 스택에 노이즈(σΨ 0.03°, σΔ 0.08°)를 더해 만들고, 모델 곡선은 이 페이지에서 Levenberg–Marquardt 로 직접 적합합니다. MSE = √(Σ((측정−모델)/σ)² / (2N−M)).

지금은 대부분의 추세 화면이 보여주는 것만 보입니다 — 두께와 MSE. (a) 와 (c) 는 둘 다 MSE ≈ 1 이라 똑같이 "좋은 핏" 으로 보입니다. 전체 진단 보기로 바꿔 보십시오.

MSE 프로파일 — n 을 고정하고 두께만 다시 적합 Cauchy A(≈ n) 를 고정값으로 묶고 d 만 재적합한 최소 MSE 입니다. 뾰족한 V 는 유일한 해, 평평한 바닥은 비유일한 해입니다. 선형 근사 오차한계(공분산)는 이런 긴 계곡을 과소평가할 수 있어 프로파일을 같이 봅니다.

슬라이더의 A 로 고정한 대안 모델은 위 세 카드의 그래프에 호박색 선으로 겹쳐 그려집니다. (c) 에서는 정답과 다른 n 의 대안 모델이 측정 곡선과 거의 구별되지 않습니다.

판정 라벨의 기준(MSE > 3 → 불량, |corr| > 0.95 또는 프로파일 배율 < 1.5 → 비유일)은 이 데모 전용 임의 기준입니다. 실제 임계값은 장비·레시피별로 정해야 하며 코드에 숫자를 박지 않는다는 것이 보고서 §1 의 설계 규칙입니다. 또 codex 경고대로, 이 데모는 경고의 전달력을 보여줄 뿐 실제 데이터에서의 비유일성 탐지 능력을 검증하지 않습니다.

기준은 "일별 4대 중앙값" 으로 잡았습니다 — 보고서가 D 의 신규 축으로 적은 골든/기준 지정 방식은 아직 정해지지 않았습니다. 기준에 이상 장비가 섞이면 중앙값이 끌려가 정상 장비(OPT01·OPT03)도 후반에 음(−)으로 흔들려 보입니다 — 기준 지정이 별도 축인 이유입니다. 판정 라벨(|평균 Δ| > 0.5 nm → bias, |기울기| > 0.03 nm/일 → drift)은 데모 전용 임의 기준입니다. 이 화면이 말하는 것은 "어느 장비가 언제부터 어긋나는 것처럼 보이는가" 까지이며, 바꿔 쓸 수 있는가(D′)는 동일 웨이퍼 짝 측정 없이는 답할 수 없습니다.
